# かみなり 台本（案）

タイトル：かみなりは、どうして光ってから音がするの？｜みのまわり図鑑 かみなり

出どころ：everyday-trivia `trivia/thunder-light-sound.md`（メモ：`ideas/notes/thunder.md`）
cast.py：正解は1番、吹き出しは B → S → K

## 1. つかみ（家の窓から。ピカッ……ゴロゴロ）
- N: 雨の日、空がピカッと光りました。
- N: 少したってから、ゴロゴロゴロ。
- B（吹き出し）: おとが あとから きた！
- N: かみなりは、どうして光ってから音がするんでしょう。

## 2. 予想
- N: どうしてだと思う？ 予想してみよう。
- N: 1番。音のほうが、とどくのがおそい。
- N: 2番。音は、あとから鳴っている。
- N: 3番。音は、雲の上で一回はね返ってくる。
- N: まずは、かみなりの正体から見てみましょう。

## 3. かみなりの正体は電気
- N: かみなりの正体は、電気です。
- N: かみなり雲の中で、あられと小さな氷のつぶがぶつかり合って、電気が分かれると考えられています。
- N: セーターをぬぐときのパチパチと、同じなかま。それがとても大きく起きているんです。
- S（吹き出し）: パチパチと おなじ！

## 4. 音の生まれかた（光と音は、ほとんど同じときに生まれる）
- N: たまった電気が一気に流れると、ピカッと光ります。
- N: そのしゅんかん、通り道のそばの空気は、1万度くらいまで一気に熱くなります。
- N: 熱くなった空気は急にふくらんで、まわりの空気を大きくふるわせます。
- N: このふるえが、ゴロゴロの音。
- N: つまり、光と音は、ほとんど同じときに生まれているんです。

## 5. 光は速く、音はおそい
- N: では、どうして音がおくれるんでしょう。
- N: 光は、1秒でおよそ30万キロメートルも進みます。
- N: 音は、1秒でおよそ340メートル。
- N: 光は、音のおよそ100万倍も速いんです。
- N: だから、同じときに生まれても、光が先に目にとどき、音はおくれて耳にとどきます。
- K（吹き出し）: ひかり、はやい〜
- N: 打ち上げ花火も同じ。花が開いてから、少しして「ドーン」と聞こえます。

## 6. 秒数をかぞえると、きょりがわかる
- N: 光ってから音が聞こえるまでの秒数をかぞえると、かみなりまでのきょりがわかります。
- N: 音は、3秒でおよそ1キロメートル進みます。
- N: いち、に、さん。3秒なら、およそ1キロメートル。
- N: 9秒なら、およそ3キロメートルです。
- N: 近いかみなりは「バリッ」とするどく、遠いかみなりは「ゴロゴロ」と低く長く聞こえます。

## 7. 音が聞こえたら、もう近い
- N: でも、ゴロゴロが聞こえたら、かみなりはもう近くにいます。
- N: すぐに、建物や車の中に入りましょう。
- N: 家の中は、基本的に安全です。
- N: 高い木の近くはあぶないので、木の下で雨やどりはしません。

## 8. 正解とみてみよう
- N: 正解は1番。光と音は同じときに生まれて、音のほうが、とどくのがおそかったんだね。
- N: かみなりの日は、家の中で、窓やかべから少しはなれて、
- N: ピカッからゴロゴロまでの秒数を、かぞえてみよう。
- N: 秒数がだんだん短くなったら、かみなりが近づいています。
- N: 外にいるときは、かぞえるより先に、建物や車の中へ入ろうね。

## 9. おわり
- S: またね！ / B: またねー！
