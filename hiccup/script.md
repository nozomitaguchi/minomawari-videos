# しゃっくり 台本

## 1. つかみ（ごはんのあと、急に「ヒック」）
- N: ごはんのあと、急に「ヒック」。
- N: 止めようと思っても、ヒック、ヒック。
- S（吹き出し）: また でた！
- N: しゃっくりは、どうして急に出て、止まらないんでしょう。

## 2. 予想（正解は1番）
- N: 予想してみよう。「ヒック」の音は、どこで鳴っているのかな？
- N: 1番。のどのおくで、とびらがしまる音。
- N: 2番。おなかの中で、空気がはねる音。
- N: 3番。鼻のおくが、ふるえる音。
- N: まずは、息をすうしくみを見てみましょう。

## 3. 息をすう筋肉「おうかくまく」
- N: むねとおなかのさかいに、「おうかくまく」という筋肉があります。
- N: ドームのような形をした、息をすうための筋肉です。
- N: おうかくまくがちぢんで下がると、空気が肺に入ります。
- N: ゆるんで上にもどると、空気はおし出されます。
- N: ふだんの息は、考えなくても、かってに続いています。

## 4. おうかくまくが、かってにピクッ
- N: ところが、このおうかくまくが、かってに、ピクッとちぢむことがあります。
- N: すると、空気が急に、ヒュッとすいこまれます。
- N: 命令を出すのは、脳のおくの、息をうけもつところだと考えられています。

## 5. 声のとびらがパタン → 「ヒック」
- N: のどのおくには、空気が通る、とびらのようなすきまがあります。
- N: 空気がすいこまれはじめると、とびらが、あっという間にパタンとしまります。
- N: いきおいよく入ってきた空気が、急にせき止められます。
- N: このときに出る音が、「ヒック」です。
- K（吹き出し）: とびらが パタン！
- N: だから「ヒック」は、息をはくときではなく、すうときに鳴るんです。

## 6. 何回もくり返す。たいていは数分。きっかけ
- N: しゃっくりは、一度はじまると、止めようとしても、しばらく何回もくり返します。
- N: 息を止めても、すぐには止まらないことがあります。
- N: でも、たいていは、数分で止まります。
- N: きっかけになるのは、炭酸の飲みものや食べすぎ、急な暑さ寒さなどです。

## 7. おなかの赤ちゃんも。何のためかは、まだなぞ
- N: おなかの中の赤ちゃんも、しゃっくりをしています。
- N: では、しゃっくりは、何のためにあるのでしょう。
- N: じつは、まだわかっていません。
- B（吹き出し）: まだ なぞなんだ！
- N: オタマジャクシは、水をすうとき、肺に入らないように、のどのとびらをしめます。
- N: これがしゃっくりとにている、という考えもあります。

## 8. 正解 と みてみよう
- N: 正解は1番。おうかくまくがピクッ、のどのとびらがパタン。その音だったんだね。
- N: 自分や家族がしゃっくりをしたら、「ヒック」が、すうときか、はくときか、耳をすませてみよう。
- N: 止めようとして、水を一気に飲んだり、食べものをたくさん飲みこんだりしないでね。
- N: ふくろを口や鼻にかぶせたり、人をおどかしたりもしないでね。
- N: 2日たっても止まらないときは、おうちの人に話して、お医者さんへ。

## 9. おわり
- S（吹き出し）: またね！
- B（吹き出し）: またねー！

## 絵のメモ
- 色の約束（サイトの図と同じ）：すう息＝あお、はく息＝オレンジ、おうかくまく＝ちゃいろ（ピクッとするときは あか）、声のとびら＝あか、しらせ（神経）＝きいろ、脳のおく＝むらさき。
- からだの絵は、前から見た図（頭はおとうと）。おうかくまく・肺・空気の通り道・声のとびらは、見やすいように大きく、かんたんに描く。
- 「吸いはじめてから0.035秒でとびらがしまる」（ストラウスたち 2003年）は、ナレーションでは「あっという間」と言い、数字は絵と概要欄に入れる。絵のピクッ → パタンは、見えるようにゆっくりにしている。
- 声のとびら（声門）は、声を出すひだ（声帯）のあいだのすき間。絵では、開いたりしまったりする「とびら」として描く。
- 「〇〇をすると止まる」とは言わない。1分に何回、最長記録などの数字は言わない（記事にない）。
- 何のためにあるかは「まだわかっていない」。オタマジャクシの話は「という考えもある」「たしかめられた答えではない」と弱めに。赤ちゃんの脳の話（UCL 2019年）は動画では言わない。
- きっかけは、炭酸の飲みもの・食べすぎ・急な温度の変化の3つを絵にする（気持ちの高ぶり・空気を飲みこむこと・お酒は言わない）。絵に「はっきりした わけが ない ことも おおい」と入れる。
- みてみようの注意：水を一気に飲まない・食べものをたくさん飲みこまない・ふくろを口や鼻にかぶせない・人をおどかさない・2日以上続いたらおうちの人に話してお医者さんへ。
