# 雪の白さ 台本

タイトル：雪は、どうして白いの？｜みのまわり図鑑 ゆき

もとの記事：everyday-trivia `trivia/snow-white.md`（メモ：`ideas/notes/snow-white.md`）

## 1. つかみ（水も氷もすきとおっているのに、雪はまっしろ）
- N: 雪は、水がこおってできたもの。
- N: 水も氷も、すきとおっています。
- N: なのに、つもった雪は、まっしろ。
- B（吹き出し）: まっしろ！
- N: 雪は、どうして白いんでしょう。

## 2. 予想（正解は1番）
- N: 予想してみよう。雪が白く見えるのは、どうしてかな？
- N: 1番。つぶのすきまで、光がはね返るから。
- N: 2番。雪に、白い色がまざっているから。
- N: 3番。雲の色が、うつっているから。
- N: まずは、雪のひとつぶを見てみましょう。

## 3. ひとつぶは すきとおった氷。すきまは空気
- N: 黒い手ぶくろに落ちた雪を、虫めがねで見てみます。
- N: ひとつぶひとつぶは、すきとおった氷です。
- K（吹き出し）: すきとおってる！
- N: つもった雪では、つぶとつぶのあいだに、すきまがあります。
- N: ふったばかりのふわふわの雪は、ほとんどが空気なんです。

## 4. 光は、氷と空気のさかいめで向きを変える
- N: 太陽の光が、雪の中に入ります。
- N: 光は、氷と空気のさかいめに当たるたびに、向きを変えます。
- N: 何度も向きを変えて、あちこちへちらばり、外へもどってきます。
- N: だから雪は、明るく見えるんです。

## 5. 氷のかたまりは、光が通りぬける
- N: 氷のかたまりには、すきまがありません。
- N: 光は、ちらばらずに通りぬけるので、すきとおって見えます。
- N: 同じ水からできていても、空気とのさかいめがあるかどうかで、見え方が変わるんです。

## 6. どの色も同じだけもどるから、白
- N: 太陽の光には、いろいろな色がまざっています。
- N: 雪のつぶは、どの色の光も、同じようにちらします。
- N: 色がかたよらずにもどってくるので、太陽の光のまま、白く見えるんです。
- N: 塩やさとうが白いのも、雲が白いのも、同じしくみです。

## 7. 雪は、当たった光の色を返す
- N: 雪は、自分の色を持っていません。当たった光の色を、そのまま返します。
- N: だから、夕やけにてらされた雪山は、赤く見えます。
- S（吹き出し）: ゆうやけの いろだ！

## 8. 深い雪のあなは青い
- N: でも、深い雪にあなをあけてのぞくと、おくのほうは青く見えます。
- N: じつは氷は、赤い光を、ほんの少しずつすいこんでいます。
- N: 雪の中を長く進んだ光ほど、赤がへって、青がのこるんです。
- N: 氷河のわれ目や氷山が青く見えるのも、同じわけです。

## 9. 正解 と みてみよう
- N: 正解は1番。つぶのすきまで光が向きを変えて、どの色ももどってくるから、白かったんだね。
- N: 雪の日に、黒い手ぶくろで雪を受けて、虫めがねでひとつぶを見てみよう。
- N: 夕方には、夕日の当たる雪が、どんな色になるか見てみてね。
- N: 外で見るときは、大人といっしょに、車の通らない場所でね。
- N: 雪は口に入れないで。太陽は、ぜったいに直接見ないでね。

## 10. おわり
- S（吹き出し）: またね！
- B（吹き出し）: またねー！

## 絵のメモ
- 「ふったばかりの雪は90〜95％が空気」は NSIDC。ナレーションでは「ほとんどが空気」と言い、数字は絵と概要欄に入れる。
- 「光をはね返す」は予想の選択肢だけ。説明では「向きを変える」と言う（本当は反射と屈折の両方）。
- 「雪には白い色がついている」とは言わない。白は雪そのものの色ではない。
- 深い雪のあな：口のあたりは黄色っぽく、深くなるにつれて黄緑 → 青緑 → あざやかな青 → 暗い（アラスカ大学 Alaska Science Forum）。何センチから青いかは言わない。
- 氷が赤い光を吸う長さ（赤は約2メートル、むらさきは約200メートルで弱まる）や「20センチ」は、ナレーションでも絵でも数字を出さない。
- 同じしくみの例は、塩・さとう・雲・あわだてた卵の白身まで（かき氷は言わない）。
- 雪のつぶ・すきま・光の道すじは、見やすいように大きく描く。
