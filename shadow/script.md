# かげ 台本（案）

タイトル：かげは、どうして自分と同じ形になるの？｜みのまわり図鑑 かげ

## 1. つかみ（晴れた日の公園。手をふると、かげも手をふる）
- N: 晴れた日に外に立つと、足もとから、黒っぽいかげがのびます。
- N: 手をふると、かげも手をふります。
- S（吹き出し）: かげも てを ふった！
- N: かげは、どうして自分と同じ形になるんでしょう。

## 2. 予想
- N: 予想してみよう。かげは、どうして同じ形になるのかな？
- N: 1番。体が、まっすぐ進む光をさえぎっているから。
- N: 2番。地面が、鏡みたいに体をうつしているから。
- N: 3番。かげが、体のまねをして動いているから。
- N: まずは、光の進みかたを見てみましょう。

## 3. 光はまっすぐ進む
- N: 光は、光るものから、まわりのあらゆる向きへ、まっすぐ進みます。
- N: 太陽の光も、まっすぐ進んできます。

## 4. さえぎると、とどかない（かげは光が少ない場所。太陽の反対がわ）
- N: 光を通さないものに当たると、光は、その先へ進めません。
- N: 光がとどかないところ。それが、かげです。
- N: かげは、黒いものがあるのではなく、まわりより光が少ない場所なんです。
- N: だから、かげはいつも、太陽と反対がわにできます。

## 5. ふちをなぞる（答えの場面。星の形の紙）
- N: では、どうして同じ形になるのか、星の形の紙で見てみましょう。
- N: ふちをかすめた光は、そのまま、かべまでとどきます。
- N: ふちの内がわに来た光だけが、さえぎられます。
- N: だから、光がとどかない場所のふちは、もののふちをなぞった線になるんです。
- B（吹き出し）: ほしの かたちだ！
- N: かげには、顔も服の色もうつりません。うつるのは、まわりの線だけです。

## 6. 形は同じでも、のびたりちぢんだり（朝・お昼・夕方）
- N: でも、かげは、のびたり、ちぢんだりします。
- N: 朝は、太陽が低いので、かげは長くなります。
- N: お昼は、太陽が高くなって、かげは短くなります。
- N: 夕方は、また長くなります。

## 7. 光に近いと大きい／お皿は上からと横から
- N: 懐中電灯の光では、ものを光に近づけるほど、かげは大きくなります。
- N: 丸いお皿も、真上から照らせば丸いかげ、真横から照らせば、細い棒のようなかげになります。
- K（吹き出し）: ぼうに なった！
- N: 光の来る向きから見たときの形が、かげになるんです。

## 8. ふちがぼやけるわけ（太陽は大きさのある光）
- N: かげのふちをよく見ると、少しぼやけています。
- N: 太陽は、点ではなく、大きさのある光だからです。
- N: ふちの近くには、太陽の光が一部だけとどいて、うすいかげになります。
- N: 手を地面からはなすほど、かげはぼんやりします。

## 9. 正解とみてみよう
- N: 正解は1番。体が、まっすぐ進む光をさえぎって、かげができていたんだね。
- N: 晴れた日に、同じ場所に立って、朝とお昼の、かげの長さと向きをくらべてみよう。
- N: 地面の近くから、手を少しずつ高く上げて、かげのふちを見てみよう。
- N: 太陽そのものは、ぜったいに見ないでね。短い時間でも、目をいためます。
- N: 道路のそばでは、車に気をつけて、大人といっしょにね。

## 10. おわり
- S（吹き出し）: またね！
- B（吹き出し）: またねー！
