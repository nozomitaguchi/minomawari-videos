# 石けんとよごれ 台本

タイトル：石けんであらうと、どうして よごれが落ちるの？｜みのまわり図鑑 せっけん

もとの記事：everyday-trivia `trivia/soap-washing.md`（メモ：`ideas/notes/soap.md`）

cast.py：正解は2番／吹き出しは B → S → K（おわりは S・B）

## 1. つかみ（水だけでは落ちない油のよごれが、石けんで落ちる）
- N: 手についた油のよごれは、水だけでは、なかなか落ちません。
- N: でも、石けんをつけてあらうと、すっきり落ちます。
- B（吹き出し）: ぴかぴか！
- N: 石けんであらうと、どうしてよごれが落ちるんでしょう。

## 2. 予想（正解は2番）
- N: 予想してみよう。石けんは、油のよごれに、何をしているのかな？
- N: 1番。油をとかして、消してしまう。
- N: 2番。油をとりかこんで、水の中へ運ぶ。
- N: 3番。あわで、油をこすり取る。
- N: まずは、水と油をまぜてみましょう。

## 3. 水と油は、まぜても分かれる
- N: コップに、水と油を入れて、まぜます。
- N: しばらくすると、油は上、水は下に、分かれてしまいます。
- N: だから油のよごれは、水だけでは、流れていかないんです。

## 4. 石けんのつぶは、マッチ棒の形
- N: 石けんのつぶを、うんと大きくして見てみましょう。
- N: マッチぼうのような形をしています。
- N: 丸い頭は、水となかよし。長いしっぽは、油となかよしです。
- S（吹き出し）: りょうほうと なかよし！

## 5. 水と油のさかいめに ならぶ
- N: 石けんのつぶは、水と油のさかいめに、ずらりとならびます。
- N: 頭は水のほうへ、しっぽは油のほうへ。こうして、水と油をなじませます。

## 6. しっぽが油にささって、とりかこむ
- N: 油のよごれに、石けんのつぶが集まってきます。
- N: しっぽが油にささって、まわりを、ぐるりととりかこみます。
- N: かこまれた油は、小さなつぶになって、水の中へはなれていきます。
- K（吹き出し）: つれていった！

## 7. すすもとりかこむ。もう布にもどらない
- N: すすのような、こなのよごれも、同じようにとりかこみます。
- N: まわりが水となかよしになったよごれは、もう布にもどりません。
- N: そして、すすぎの水といっしょに、流れていきます。

## 8. ミセル
- N: 石けんのつぶは、水の中でたくさん集まると、頭を外に向けた、小さな玉をつくります。
- N: この玉を「ミセル」といい、内がわに、よごれを取りこみます。

## 9. 石けんは、油とアルカリから作る
- N: ところで石けんは、何からできているのでしょう。
- N: じつは、牛のあぶらやヤシの油などに、アルカリというものをまぜて作ります。
- N: 油のよごれを落とす石けんは、油からできていたんです。
- N: アルカリは、あぶない薬。石けん作りは、まねしないでね。

## 10. 正解 と みてみよう
- N: 正解は2番。石けんが油のよごれをとりかこんで、水の中へ運んでいたんだね。
- N: 大人といっしょに、ふたのしまるボトルに、水と油を少し入れて、ふってみよう。
- N: おいておくと、上と下に分かれるかな。
- N: つぎに、石けんを少したしてふると、どう変わるかな。
- N: 石けん水は、のまないで。目にも入れないでね。
- N: おわったら、手をあらおう。

## 11. おわり
- S（吹き出し）: またね！
- B（吹き出し）: またねー！

## 絵のメモ
- 色は記事の図とそろえる：水は青、油は黄色、石けんの分子は「赤い丸い頭（水となかよし）＋黒いぎざぎざのしっぽ（油となかよし）」、すすは黒い粒。
- 「石けんのつぶ」は石けんの分子のこと（記事の子どもむけの言い方）。本物は目に見えないほど小さい。概要欄に書く。
- とりかこむ・布にもどらない・ミセルは、製品評価技術基盤機構と日本石鹸洗剤工業会が「界面活性剤」のはたらきとして説明しているもの。石けんは界面活性剤の一つ。
- 「あわがよごれを落とす」とは言わない（3択のまちがいの選択肢にだけ使う）。
- ウイルス・ばい菌の話、石けんの歴史、日本の水が軟水かどうかは入れない（メモの注意）。
- 4つのはたらきのうち「しみこむ（浸透）」と、硬い水・石けんカスの話は、長さのつごうで入れていない。
- ミセルは、石けんがある濃さをこえたときにできる。ナレーションでは「たくさん集まると」と言う。
- 石けんを足してふったボトルがどうなるかは、絵で見せない（予想してくらべてもらう）。
- 注意書き：石けん水は飲まない・目に入れない、終わったら手を洗う、アルカリはあぶない薬なので石けん作りはまねしない。
