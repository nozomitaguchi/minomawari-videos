# いぬ（ハアハア）台本

出どころ：everyday-trivia `trivia/dog-panting.md`（暑い日や走りまわったあと、犬は口を大きく開けて舌をだらんと出し、ハアハアと速く浅い息をする・犬の汗腺は主に肉球にしかなく、人のように汗をかいて体温を調節できない（鳥取県・環境省）。犬や猫の汗はわずかで、体を冷やす役目は小さいと考えられている（MSD獣医マニュアル）・ぬれたものから水が蒸発するとき、まわりから熱をうばう（環境省のシンポジウム資料）。プールから上がるとひんやりするのと同じ（記事の6〜9歳むけ）・ハアハアでは、呼吸の通り道、とくに鼻の奥のひだ・鼻のまわりの空洞・舌から水が蒸発して熱が逃げる（2025年の総説）・暑さでハアハアしている犬では、吸う空気のほとんどが鼻から入り、口から出ていく（1970年の論文）・鼻の中の「外側鼻腺」から、冷やすための水が出る。出口は鼻の穴の入り口から2cmほど奥（1972年の論文）・舌の血の流れは、20℃で休んでいるとき平均1分に11mL、38℃でハアハアしているとき平均60.4mLと5倍あまり。舌は蒸発で熱を捨てるのを助けていると考えられている（1976年の論文）・電球で温めた体重12kgほどの犬で、ハアハアは1秒に平均5.33回。胸と呼吸の通り道がいちばんゆれやすいリズムは1秒に平均5.28回で、ほぼ同じ。このリズムだと、いちばん少ない力で、いちばんたくさんの空気を動かせる。ブランコをちょうど合うタイミングで押すと小さな力で大きくゆれるのと同じ考え方（1962年の論文）・蒸し暑い環境では熱をうまく逃がせず、熱中症にかかりやすい（鳥取県）・暑い日の散歩は早朝や夕方以降の涼しい時間に（東京都）。短い時間でも犬を車の中に残さない（環境省）・みてみよう：散歩している犬をはなれたところから見て、歩きはじめと走ったあとで、口の開き方と息の速さをくらべる。知らない犬には近づかない。さわりたいときは飼い主の了解をもらってから（千葉市））／`ideas/notes/dog-panting.md`（見せ場・場面の順番・注意書き）

言い方の注意：「犬はまったく汗をかかない」とは言わない（「汗をかけるのは、ほぼ肉球だけ」）。「舌で冷やしている」だけにしない（水がかわくのは口と鼻の中のぬれたところ。舌は「手つだっていると考えられています」）。「鼻から吸って口から出す」は、暑くてハアハアしているときの「ことが多い」と言い、いつもとは言わない（すずしいときは鼻だけ、もっと暑いと口からも吸う。概要欄の注に書く）。「5倍あまり」は、20℃で休んでいるときと38℃でハアハアしているときの舌の血の流れのくらべ。「1秒に5回くらい」は、電球で温めた体重12kgほどの犬の実験なので「ある実験では」と言う。ブランコはたとえ。うれしいとき・こうふんしたときのハアハアは、確かめられていないので言わない。熱中症の合図・鼻の短い犬・地面の熱・空気の通り道が3つあること・鼻のおくの水の量（1時間に9.6g）・湿度80％は入れない（時間の都合）。犬の頭を切った絵・鼻のおくのひだ・水の出るところ・血のすじは、わかりやすくした絵で、本物の形や大きさではない。絵の中の犬のハアハアは、1秒に5回の速さで動かしている。


## 1. つかみ（hook）
- N: 暑い日や、たくさん走ったあと。犬は、口を大きくあけて、舌をだらんと出します。
- N: そして、ハアハアと、速い息をします。
- S（吹き出し）: ずっと ハアハア してる！
- N: 犬は、どうして、舌を出してハアハアするんでしょう。

## 2. 予想（guess）
- N: ヒントは、汗。犬が汗をかけるのは、どこだと思う？
- N: 1番。体じゅう。
- N: 2番。足のうらの、肉球。
- N: 3番。舌の上。
- N: 人とくらべながら、見てみましょう。

## 3. 人は体じゅうに汗、犬はほぼ肉球だけ（sweat）
- N: 人は、暑いと、体じゅうに汗をかいて、体を冷やします。
- N: でも、犬が汗をかけるのは、ほぼ、足のうらの肉球だけ。
- B（吹き出し）: にくきゅう だけ！？
- N: その汗はわずかで、体を冷やす役目は、小さいと考えられています。

## 4. 水はかわくとき、熱を持っていく（evap）
- N: そこで犬が使うのは、口と鼻の中の、ぬれたところです。
- N: ぬれたものがかわくとき、水は、まわりの熱を持っていきます。
- N: プールから上がると、ひんやりするのと同じです。
- N: 犬は、口と鼻の中の水をかわかして、体の熱を、外へすてているんです。

## 5. 鼻から吸って口から出す・鼻のおくの水・舌に血が5倍あまり（nose）
- N: ハアハアのとき、犬は、鼻から吸って、口から出すことが多いんです。
- S（吹き出し）: はなから すってるんだ！
- N: 鼻のおくからは、冷やすための水が、出てきます。
- N: 暑くてハアハアしているとき、舌には、すずしいときの5倍あまりの血が流れます。
- N: 舌も、熱をすてるのを、手つだっていると考えられています。

## 6. 1秒に5回くらいの、ちょうどいいリズム（rate）
- N: ある実験では、ハアハアは、1秒に5回くらいでした。
- N: これは、犬の胸が、いちばんゆれやすいリズムです。
- N: ブランコを、ちょうどいいタイミングで押すと、小さな力で大きくゆれますね。
- N: それと同じで、少ない力で、たくさんの空気を動かせるんです。

## 7. むし暑い日は冷えにくい・散歩と車の注意（humid）
- N: でも、むし暑い日は、水がかわきにくくなります。
- N: ハアハアしても、体が冷えにくいんです。
- N: だから、暑い日の散歩は、すずしい朝や夕方に。
- N: 短い時間でも、車の中に、犬を残してはいけません。

## 8. 正解とみてみよう（look）
- N: 正解は2番。犬が汗をかけるのは、ほぼ、足のうらの肉球だけ。
- N: だから、ハアハアして、体を冷やしていたんだね。
- N: 散歩している犬を、はなれたところから見てみよう。
- N: 歩きはじめと、走ったあと。口のあき方と、息の速さは、どうちがうかな。
- N: 知らない犬には、近づかないでね。
- N: さわりたいときは、飼い主の人に、聞いてからにしよう。
