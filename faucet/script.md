# じゃぐち 台本（案）

タイトル：蛇口をひねると、どうしていつでも水が出てくるの？｜みのまわり図鑑 じゃぐち

出どころ：everyday-trivia `trivia/faucet-water-pressure.md`（メモ：`ideas/notes/faucet.md`）
cast.py：正解は3番、吹き出しは S → B → S

## 1. つかみ（洗面台。ひねると、すぐジャーッ）
- N: 手をあらうとき、蛇口をひねると、すぐに水がジャーッと出てきます。
- S（吹き出し）: すぐ でた！
- N: 朝でも夜でも、ひねったとたんに出てきます。
- N: 蛇口をひねると、どうしていつでも水が出てくるんでしょう。

## 2. 予想
- N: どうしてだと思う？ 予想してみよう。
- N: 1番。蛇口の中に、水がためてあるから。
- N: 2番。ひねると、蛇口が水をすいこむから。
- N: 3番。管の中の水が、いつもおされているから。
- N: まずは、蛇口の中をのぞいてみましょう。

## 3. 蛇口の中（コマが上がると、通り道が開く）
- N: これは、蛇口を横から切って、中を見た絵です。
- N: 中には「コマ」という、ゴムのついた小さな部品があります。
- N: しまっているときは、コマが水の通り道をふさいでいます。
- N: ハンドルを回すと、コマが上がって、通り道が開きます。
- B（吹き出し）: ふたが あがった！

## 4. 管の中の水は、いつもおされている
- N: でも、通り道を開けただけで、どうしてすぐに水が出るんでしょう。
- N: 蛇口のおくの管は、道路の下の太い管までつながっています。
- N: 管の中の水も、蛇口の手前までずっとつながっていて、
- N: その水は、いつもぎゅっとおされています。
- N: だから、通り道を開けたとたんに、水が出てくるんです。
- N: 道路の下の管では、おす力が弱くなりすぎないように、国の決まりもあります。

## 5. だれがおしている？ 高台の配水池
- N: では、だれが水をおしているんでしょう。
- N: ひとつは、高台に作られた「配水池」。水をためておく所です。
- N: 水は、高い所から低い所へ流れようとします。
- N: その力が、管の中の水をぐいぐいおしているんです。
- S（吹き出し）: たかい ところから！

## 6. 高台がない所はポンプ（東京は24時間体制で調節）
- N: 高い所に配水池を作れない場所では、ポンプで水をおして送ります。
- N: 東京では、時間ごとに変わる水を使う量に合わせて、
- N: 送る量やおす力を、24時間体制で調節しています。

## 7. 高い建物へは、どうとどける？（東京の決まり）
- N: では、高い建物の上の階には、どうやってとどけるんでしょう。
- N: 東京では、3階くらいまでは、道路の下の管のおす力だけでとどきます。
- N: それより高い階には、ポンプで力を足しておし上げたり、
- N: 屋上のタンクにくみ上げて、そこから流したりして、とどけます。

## 8. 正解とみてみよう
- N: 正解は3番。高い所にためた水とポンプが、管の中の水を、いつもおしていたんだね。
- N: 大人といっしょに、蛇口を少しだけ回したときと、もう少し回したときで、
- N: 水の太さと音をくらべてみよう。見たら、すぐしめようね。
- N: お湯の出る蛇口は熱いので、さわりません。蛇口を分解するのもやめようね。
- N: 外では、高い建物の屋上に、箱の形のタンクがあるか、さがしてみよう。
- N: 屋上やタンクには近づかないで、下から見るだけにしようね。

## 9. おわり
- S: またね！ / B: またねー！

## 言い方のメモ（元記事とメモから）
- 「3階くらいまで」「それより高い階はポンプか屋上のタンク」は東京都の決まりなので「東京では」と言う。
- コマは「ハンドルを回すと上下して開け閉めする」まで。「水の力でコマがおし上げられる」とは言わない（絵でも、コマはハンドルのじくといっしょに上がる）。
- 「24時間休まず送る」ではなく「24時間体制で調節」。
- 配水池の高さ・150キロパスカルなどの数字は言わない（国の決まりがある、まで）。
