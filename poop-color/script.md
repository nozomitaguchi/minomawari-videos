## 1. つかみ（hook）
- N: にんじんは、オレンジ。ほうれんそうは、緑。
- N: いろいろな色のものを食べても、うんちは、だいたい茶色です。
- S（吹き出し）: なんで ちゃいろ？
- N: うんちは、どうして、茶色いんでしょう。

## 2. 予想（guess）
- N: うんちは、どうして茶色いと思う？
- N: 1番。茶色い食べものを、たくさん食べているから。
- N: 2番。いろいろな色の食べものが、おなかの中で、まざるから。
- N: 3番。古くなった血からできた色のもとを、おなかの細菌が、茶色に変えるから。
- N: 色のもとを、体の中で、たどってみましょう。

## 3. 茶色のもとは、食べものの色ではない（food）
- N: じつは、茶色のもとは、食べものの色ではありません。
- N: 体の中でつくられる、色なんです。

## 4. 血の赤いつぶ → 黄色いもと（blood）
- N: はじまりは、血の中の、赤いつぶ。
- N: 赤いつぶには、赤い色のもとが、入っています。
- N: 赤いつぶは、古くなると、こわされます。
- N: すると、赤い色のもとは、黄色っぽいものに変わるんです。
- B（吹き出し）: きいろに なった！

## 5. 胆汁にまざって、小腸へ（bile）
- N: 黄色いもとは、肝臓がつくる、胆汁という液にまざります。
- N: 胆汁は、あぶらを体にとりこむのを、助ける液です。
- N: そして、胆汁といっしょに、小腸へ流れこみます。

## 6. 腸の細菌が変える（bacteria）
- N: 腸の中には、目に見えないほど小さな細菌が、すんでいます。
- N: この細菌が、黄色いもとを、べつのものに変えます。
- N: その一部は、血にもどって、おしっこの黄色のもとになります。
- S（吹き出し）: おしっこも！
- N: 残りは、もっと茶色いものに変わって、うんちを茶色くするんです。

## 7. 白っぽいうんちと、便色カード（pale）
- N: 胆汁が腸にとどかないと、茶色いものがあまりできず、うんちは白っぽくなります。
- N: だから、うんちの色は、お医者さんが病気を見つける手がかりになります。
- N: 赤ちゃんのうんちの色をくらべる、べんしょくカードも、あります。
- N: 1番から7番までの、色の見本です。日本では、母子健康手帳にとじこまれています。
- N: うすい色の、1番から3番に近いときは、すぐに専門のお医者さんにみてもらいます。

## 8. 生まれてさいしょのうんち（baby）
- N: 生まれてさいしょのうんちは、茶色ではなく、濃い緑色。
- N: 生まれてから、ふつう、12時間から24時間のうちに、出ます。

## 9. 正解とみてみよう（look）
- N: 正解は3番。古くなった血からできた色のもとを、細菌が茶色に変えていたんだね。
- N: おうちに、母子健康手帳があったら、べんしょくカードのページを、見てみよう。
- N: 1番から7番まで、色がどう変わっていくかな。
- N: ふだんの茶色いうんちは、何番に近いか、予想してから見ると、おもしろいよ。
- N: 手帳は、おうちの人といっしょに見てね。うんちは、見るだけで、さわらないでね。

## 10. おわり（end）
- S（吹き出し）: またね！
- B（吹き出し）: またねー！
