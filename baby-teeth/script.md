言い方の注意：「最初に生えるおとなの歯は6歳臼歯」とは言い切らない（下の前歯とどちらが先かは子どもによる）。二枚歯・根がとけるまでの期間・乳歯をなくすと隣の歯が動く話は、出典で確かめられていないので入れない。「ぬけるからむし歯はそのままでいい」とは言わない。とかしはじめる合図（おとなの歯をつつむふくろ）・破歯細胞と破骨細胞のちがい・下におとなの歯がない乳歯・親知らず・2億500万年前・ネズミのなかまは、時間の都合で入れない。「ぬけた歯の根もとを見てくらべる」も、時間の都合でナレーションからは外した。断面の絵は、図鑑の絵（bt-step-grow / melt / wobble / out）と同じ並べ方で、位置と向きを変えずに根の長さとおとなの歯の高さだけを動かす。細胞は、わかりやすく大きくかいたもの。

## 1. つかみ（hook）
- N: ぐらぐらしていた歯が、ぽろっと、ぬけました。
- S（吹き出し）: ぬけた！
- N: ぬけた歯を、よく見ると、根っこが、ほとんどありません。
- N: 根っこは、どこへ行ったんでしょう。
- N: 子どもの歯は、どうして、生えかわるんでしょう。

## 2. 予想（guess）
- N: 根っこがほとんどないのは、どうしてだと思う？
- N: 1番。下のおとなの歯が、上へ来ると、根っこがとけるから。
- N: 2番。子どもの歯には、はじめから、根っこがないから。
- N: 3番。歯をみがくと、根っこが、すりへるから。
- N: 歯ぐきの中を、のぞいてみましょう。

## 3. 歯ぐきの中（under）
- N: 下のあごを、たてに切って、横から見てみます。
- N: 子どもの歯にも、歯ぐきの中に、根っこがあります。
- N: そのすぐ下、あごの骨の中で、もう、おとなの歯が育っています。
- N: おとなの歯づくりは、生まれたころに、もう始まっています。
- B（吹き出し）: もう いるの！？

## 4. 根っこがとける（melt）
- N: おとなの歯が上へ動いてくると、子どもの歯の根っこが、少しずつとけて、短くなります。
- N: とかすのは、歯のかたいところをとかす、小さな細胞です。
- N: これは、病気ではなく、ふつうのできごとです。

## 5. ぐらぐら → ぬける（wobble）
- N: 根っこがほとんどなくなると、歯を止めているのは、まわりの歯ぐきくらい。
- N: だから、舌や指でさわると、ぐらぐら動くんです。
- N: ぽろっとぬけると、あいたところへ、おとなの歯が出てきます。
- K（吹き出し）: でてきた〜

## 6. どうして2組？（why）
- N: でも、どうして、はじめから、おとなの歯じゃないんでしょう。
- N: 小さい子の小さな顔には、小さな歯が、ちょうどいいからです。
- N: 顔が大きくなると、大きくて数の多い歯が、入るようになります。
- N: 子どもの歯は20本。おとなの歯は、28本から32本です。
- N: サメやワニは、何度でも生えかわりますが、ヒトは、1回だけです。

## 7. ぬける順番と6歳臼歯（molar）
- N: 最初にぬけるのは、ふつう、下のまん中の前歯。6歳から7歳ごろです。
- N: 6歳ごろには、いちばん奥の歯の、さらに奥に、新しい奥歯も生えてきます。
- N: この歯は、どの歯も追い出さずに、あいている場所に生えます。

## 8. 正解とみてみよう（look）
- N: 正解は1番。下のおとなの歯が上へ来ると、根っこがとけるからだったんだね。
- N: 鏡の前で口を大きくあけて、いちばん奥の歯の、さらに奥を見てみよう。
- N: 新しい大きな奥歯が、顔を出しているかもしれないよ。
- N: 見るだけにして、指を、口の奥まで入れないでね。
- N: ぐらぐらの歯は、むりに引っぱらないで、自然にぬけるのを待とう。
- N: なかなかぬけないときは、歯医者さんに相談してね。
