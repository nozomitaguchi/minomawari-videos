# 海の水のしょっぱさ 台本

タイトル：海の水は、どうして しょっぱいの？｜みのまわり図鑑 うみ

もとの記事：everyday-trivia `trivia/sea-salty.md`（メモ：`ideas/notes/sea-salty.md`）

cast.py：正解は2番／吹き出しは S → K → B（おわりは S・B）

## 1. つかみ（海はしょっぱいのに、川も雨もしょっぱくない）
- N: 海であそんでいて、水が口に入ると、しょっぱいですね。
- N: でも、海に流れこむ川の水は、しょっぱくありません。
- N: 空からふる雨も、しょっぱくない。
- S（吹き出し）: かわは しょっぱくないのに？
- N: 海の水は、どうしてしょっぱいんでしょう。

## 2. 予想（正解は2番）
- N: 予想してみよう。海の水がしょっぱいのは、どうしてかな？
- N: 1番。海の生きものが、塩を出しているから。
- N: 2番。山の岩からとけた塩を、川が運んでくるから。
- N: 3番。海の底に、大きな塩のかたまりがあるから。
- N: まずは、海の水の中を見てみましょう。

## 3. 海の水には塩がとけている（1キログラムに およそ35グラム）
- N: 海の水には、塩がとけています。
- N: 海の水1キログラムをかわかすと、塩などが、平均でおよそ35グラムのこります。
- N: いちばん多いのは、台所の食塩のもとと、同じものです。

## 4. 塩のふるさとは山の岩
- N: この塩は、どこから来たのでしょう。
- N: 雨には、空気の中のガスが、少しとけています。
- N: その雨が、山の岩を、ほんの少しずつとかします。
- K（吹き出し）: いわが とけるの！？

## 5. 川が海へ運ぶ。海の底からも加わる
- N: とけたものは、川にのって、海へ運ばれます。
- N: 世界じゅうの川が運ぶ塩は、1年におよそ40億トン、という見つもりがあります。
- N: 海の底の、熱い水がふき出すところからも、加わります。

## 6. どうして川はしょっぱくない？
- N: では、どうして川は、しょっぱくないのでしょう。
- N: 川には、雨の新しい水が、いつもたされるからです。

## 7. 水だけが空へ、塩はのこる
- N: 海は、すべての川から、塩を集めます。
- N: そして海からは、水だけが蒸発して、空へ出ていきます。
- N: 塩は、海にのこります。
- B（吹き出し）: しおだけ のこった！
- N: 空へ行った水は、雲になり、雨になって、また川を流れてきます。

## 8. これからも、どんどんしょっぱくなる？
- N: できたばかりの海は、少ししょっぱいくらいだったと考えられています。
- N: 長い長い時間をかけて、雨が岩のものを運び、海はしょっぱくなりました。
- N: では、海はこれからも、どんどんしょっぱくなるのでしょうか。
- N: 今は、川から入ってくる塩と、海の底につもる塩が、だいたい同じ。
- N: だから、これ以上はしょっぱくならないと、考えられています。

## 9. 正解 と みてみよう
- N: 正解は2番。山の岩からとけた塩を川が運び、水だけが空へ出ていくから、しょっぱかったんだね。
- N: 大人といっしょに、塩水を小皿に少し入れて、日の当たるまどべに置いてみよう。
- N: 水がなくなったら、何がのこるかな。毎日見てみてね。
- N: 地図では、山から海まで、川を指でたどってみよう。
- N: 塩水は口に入れないで、小さい子の手がとどかないところに置こうね。
- N: 海であそぶときも、海の水は、のまないでね。

## 10. おわり
- S（吹き出し）: またね！
- B（吹き出し）: またねー！

## 絵のメモ
- 塩のおもなもとは「陸の岩」。海の底の熱い水は「〜からも加わる」と脇役で言う（記事・メモのとおり）。
- 水にとけた塩は目に見えない。白いひしがたのつぶは、見やすくするための絵（場面3で「ほんとうは めに みえないよ」と出す。概要欄にも書く）。
- 塩化物イオンとナトリウムの割合は資料で幅がある（85〜90％以上）ので、数字は出さず「いちばん多い」と言う。
- 35グラムは「平均」、40億トンは「見つもり」（NOAA）と言う。5京トン・166メートルは今回は入れない。
- 雨にとけている「空気の中のガス」は二酸化炭素（記事）。ナレーションと絵では「ガス」とだけ言い、概要欄に書く。
- 「もうしょっぱくならない」は「〜と考えられています」と言う。
- 死海で体がうくこと、洗濯物や汗の例は言わない（メモの注意）。
- みてみよう：塩水の小皿（大人といっしょに・口に入れない・小さい子の手がとどかないところ）、地図で川をたどる。海の水は飲まない、を必ず入れる。
- 山・川・海の絵は断面の図。大きさの比は本物とちがう。
