# こえ（録音した自分の声） 台本

タイトル：録音した自分の声は、どうしてちがって聞こえるの？｜みのまわり図鑑 こえ
出どころ：everyday-trivia `trivia/voice-recorded.md`（音が耳の奥にとどく道は2つ：空気の道＝耳の穴→こまく→3つの小さな骨→うずまき、骨の道＝頭の骨がふるえて こまくを通らずに うずまきへ・話すときは2つがまざって聞こえる・マイクは空気のふるえしか拾えない・骨の道は高い音ほど弱めると考えられている→自分で聞く声は低い音が強い・録音の声はまわりの人が聞いている声・耳をふさいでも主に骨の道で聞こえ、大きくこもってひびく・みてみよう）／メモ `ideas/notes/recorded-voice.md`
正解：3番（cast.py）／吹き出し：B → S → B（おわり S・B）
色の約束：くうきの みち＝あお、ほねの みち＝オレンジ、うずまき＝むらさき
言い方の注意：「骨の道は低い音だけが通る」と言いきらない（「高い音ほど弱めると考えられている」まで）。「家族の声の録音はいつもと同じに聞こえる」とは言わない。「自分の声がきらい・はずかしい」という気持ちの話はしない。耳の中の筋肉の話はしない。3択の1番・2番（マイクやスピーカーのせい）は、記事にない話なので、はっきり打ち消すことばは入れず、「録音の声は、まわりの人がいつも聞いている声」で答える。


## 1. つかみ（hook）
- N: スマホで、自分の声を録音して、聞いてみると…。
- N: あれ？ いつもの声と、なんだかちがう。
- B（吹き出し）: これ、ぼくの こえ？
- N: 録音した自分の声は、どうしてちがって聞こえるんでしょう。

## 2. 予想（guess）
- N: どうしてだと思う？ 予想してみよう。
- N: 1番。マイクが、声を高く変えてしまう。
- N: 2番。スピーカーが小さくて、声が細くなる。
- N: 3番。いつもの声には、頭の骨を通る音がまざっている。
- N: まずは、音が耳の奥にとどく道を見てみましょう。

## 3. 音がとどく道は2つ（空気の道・骨の道）（paths）
- N: 音が耳の奥にとどく道は、2つあります。
- N: 1つめは、空気の道。
- N: 空気のふるえが耳の穴に入って、こまくをふるわせます。
- N: そのふるえが、3つの小さな骨を通って、うずまきの形をしたところにとどきます。
- N: ほかの人の声や、まわりの音は、ふつうこの道で聞いています。
- N: 2つめは、骨の道。
- N: 頭の骨そのものがふるえて、こまくを通らずに、直接うずまきにとどきます。

## 4. 話すと、2つの道の声がまざる（mix）
- N: 自分が話すと、口から出た声は、空気を通って、ぐるっと自分の耳に入ります。
- N: 同時に、声のふるえは、頭の骨や体の中を通って、うずまきにとどきます。
- N: いつも聞いている自分の声は、この2つがまざった音なんです。

## 5. 録音に入るのは、空気の道だけ（rec）
- N: でも、録音するマイクは、空気のふるえしか拾えません。
- N: 頭の中を通る骨の道の音は、マイクには入りません。
- N: だから録音の声は、空気の道の音だけになります。

## 6. 骨の道は高い音ほど弱める → 録音は低いひびきが足りない（low）
- N: 骨の道は、高い音ほど弱めると考えられています。
- N: だから、いつも自分で聞く声は、低い音が強く聞こえます。
- N: 録音の声が高く、細く聞こえるのは、その低いひびきが足りないからです。
- S（吹き出し）: わたしの こえ、こんなに たかい？

## 7. 録音の声は、まわりの人が聞いている声（others）
- N: まわりの人には、あなたの声は、空気の道だけでとどきます。
- N: つまり録音の声は、家族や友だちがいつも聞いている、あなたの声なんです。
- N: とどく道がちがうのは、自分の声だけです。

## 8. 耳をふさぐと、骨の道がよくわかる（cover）
- N: 耳を手でふさいで声を出しても、自分の声は聞こえます。
- N: そのとき聞こえているのは、おもに骨の道の音です。
- N: しかも声は、かえって大きく、こもったようにひびきます。
- B（吹き出し）: あー！ ボワンって なった！

## 9. 正解とみてみよう（look）
- N: 正解は3番。いつもの自分の声には、頭の骨を通る音が、まざっていたんだね。
- N: 手のひらで両耳をそっとおおって、「あー」と言ってみよう。
- N: おおわないときと、声がどうちがうか、くらべてみてね。
- N: 家族と同じことばを録音して、聞きくらべてみるのもおすすめです。
- N: 耳の穴に、指や物を入れないでね。
- N: 耳のそばで、大きな声を出すのもやめようね。

## 10. おわり（end）
- S: またね！ / B: またねー！
