# こおり 台本（案）

タイトル：こおりは、どうして とけるの？｜みのまわり図鑑 こおり

出どころ：everyday-trivia `trivia/ice-melt.md`（メモ：`ideas/notes/ice-melt.md`）
cast.py：正解は3番、吹き出しは S → K → B

## 1. つかみ（冷凍庫から出した氷が、お皿の上で水になる）
- N: 冷凍庫から出した氷を、お皿にのせておきます。
- N: しばらくすると、だんだん小さくなって、水になりました。
- S（吹き出し）: だれが とかしたの？
- N: 氷は、どうしてとけるんでしょう。

## 2. 予想（アルミの板と あわの板）
- N: 予想してみよう。アルミの板と、プラスチックのあわでできた板に、同じ氷をのせます。
- N: 早くとけるのは、どっち？
- N: 1番。あわの板の上。
- N: 2番。どちらも同じ。
- N: 3番。アルミの板の上。
- N: 答えをさがしに、まずは氷の中をのぞいてみましょう。

## 3. 氷の中（水のつぶが きちんと並んで、手をつないでいる）
- N: 氷の中では、水のつぶが、きちんと並んでいます。
- N: となりのつぶと、ぎゅっと手をつないでいるんです。
- N: 1つのつぶが、まわりの4つとつながって、すきまの多い形になっています。

## 4. 熱は、あたたかいものから氷へ
- N: 氷を手にのせると、ひやっと冷たいですね。
- N: これは、手の熱が、氷にうばわれているからです。
- N: 熱は、あたたかいものから、氷へうつります。
- N: 手だけでなく、空気やお皿からも、氷に熱が入ってきます。
- K（吹き出し）: ぽかぽかが うつった〜

## 5. 入った熱は、つぶの手をはなすのに使われる
- N: 入ってきた熱は、つぶの手をはなすのに使われます。
- N: 手をはなしたつぶは、ばらばらに動けるようになります。
- N: これが、水です。
- N: 氷をとかしていたのは、まわりから入ってくる熱だったんですね。

## 6. とけているあいだは 0度のまま
- N: ふしぎなことに、とけているあいだ、氷の温度は0度のまま変わりません。
- N: 入った熱が、手をはなすのに使われているからです。
- N: ぜんぶとけて水になってから、また温度が上がりはじめます。

## 7. くらべる（アルミの板と あわの板）
- N: では、2まいの板にもどりましょう。
- N: アルミの板と、あわの板。どちらも、部屋と同じ温度です。
- N: 氷をのせて1分ほどたつと、アルミの上の氷は、半分以上とけました。
- N: あわの板の上は、まだほとんどこおったまま。
- B（吹き出し）: アルミの かち！
- N: アルミは、熱をとてもよく伝えます。板の下や横から、氷のほうへ熱が流れこむんです。
- N: あわの板は、熱をとても伝えにくいので、熱が通るのに長い時間がかかります。

## 8. さわると、アルミは冷たく感じる
- N: この2まいの板、さわってみると、アルミのほうが冷たく感じます。
- N: 同じ温度なのに、アルミは、手の熱を早くうばうからです。
- N: 手で冷たく感じる板ほど、氷を早くとかすんですね。

## 9. 正解とみてみよう
- N: 正解は3番。アルミの板の上のほうが、早くとけるんだね。
- N: おうちでは、アルミのトレーと、発泡スチロールのトレーでためせます。
- N: 先に両方さわって、どちらの氷が早くとけるか、予想してから見てみよう。
- N: 氷は、大人に出してもらってね。口に入れて遊ばないでね。

## 10. おわり
- S: またね！ / B: またねー！

## メモ
- 板の実験（1分ほどで半分以上・あわの板はほとんどこおったまま・どちらも部屋と同じ温度）は、カリフォルニア大学サンタバーバラ校・サンタクルーズ校の演示実験。2まいとも黒い板なので、絵も黒い板にしている。
- 「あわの板」＝かたいプラスチックのあわ（発泡プラスチック）の板。おうちでためすときは食品の発泡スチロールのトレー（元記事の「みてみよう」）。
- 氷が水にうく話・10円玉と100円玉・冬の道の塩は、長さの都合で入れていない。
