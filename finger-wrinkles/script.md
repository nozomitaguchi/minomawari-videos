# ゆびの しわしわ 台本（案）

タイトル：おふろに はいると、どうして ゆびが しわしわに なるの？｜みのまわり図鑑 ゆび

出どころ：everyday-trivia `trivia/finger-wrinkles.md`（メモ：`ideas/notes/finger-wrinkles.md`）
cast.py：正解は1番、吹き出しは S → B → K

## 1. つかみ（おふろで、指先がしわしわに）
- N: おふろに入っていると、指先がしわしわになります。
- N: 入ったばかりのときは、つるつるだったのに。
- S（吹き出し）: みずを すったのかな？
- N: おふろに入ると、どうして指がしわしわになるんでしょう。

## 2. 予想
- N: どうしてだと思う？ 予想してみよう。
- N: 1番。指の中の血管が、きゅっとちぢむから。
- N: 2番。皮ふが水を吸って、ふくらむから。
- N: 3番。お湯の熱で、皮ふがのびるから。
- N: まずは、皮ふのいちばん外側から見てみましょう。

## 3. 外側の細胞は、水を吸うとふくらむ（昔の考え）
- N: 皮ふのいちばん外側の細胞は、水を吸うとふくらみます。
- N: だから昔は、指のしわも、皮ふがふくらむせいだと考えられていました。
- N: でも、それだけではなかったんです。

## 4. 手がかりは神経
- N: 手がかりは、神経です。
- N: 神経がはたらかなくなった指は、水につけても、しわになりません。
- N: つまり、しわは、体が自分でつくっているんです。
- B（吹き出し）: じぶんで つくってるの！？
- N: はたらいているのは、心臓や汗と同じように、自分で考えなくても動く神経です。

## 5. しわができる順番 ①②（考えられているしくみ）
- N: しわができる順番は、こう考えられています。
- N: まず、水が、手のひらにたくさんある汗の出口から、皮ふの中にしみこみます。
- N: すると、まわりの神経が、合図をたくさん出します。

## 6. しわができる順番 ③④
- N: 合図を受けて、指先の血管が、きゅっとちぢみます。
- N: 血管がちぢむと、指先の中身が少しへります。
- N: すると、上の皮ふが下へ引っぱられて、しわになるんです。
- K（吹き出し）: きゅっと ちぢんだ〜

## 7. しわの形は、毎回同じ
- N: ちなみに、しわの形は、毎回同じです。
- N: 1日以上あけて、もう一度水につけても、同じ形のしわができました。
- N: しわのもとになる血管が、ほとんど場所を変えないからだそうです。

## 8. 何のため？（まだわかっていない）
- N: では、このしわは、何のためにあるのでしょう。
- N: 雨の日のタイヤのみぞのように、ぬれたものをつかみやすくするため、という考えがあります。
- N: ある実験では、しわしわの指のほうが、水の中のビー玉を早く移せました。
- N: でも、べつの実験では、ちがいが出ませんでした。
- N: しわが何のためにあるのかは、まだわかっていないんです。

## 9. 正解とみてみよう
- N: 正解は1番。指の中の血管がちぢんで、皮ふが引っぱられていたんだね。
- N: 皮ふが水を吸ってふくらむのも本当。でも、それだけでは、しわになりません。
- N: おふろで、指先と手のこうをくらべてみよう。どっちが先に、しわしわになるかな。
- N: おふろは、大人といっしょに。熱いお湯に長く入りすぎないで、のぼせる前に出ようね。

## 10. おわり
- S: またね！ / B: またねー！

## メモ
- しわができる順番（水がしみこむ → 神経が合図 → 血管がちぢむ → 皮ふが引っぱられる）は、ウィルダー＝スミスの2004年のまとめの論文が「おそらく」として書いたもの。動画でも「こう考えられています」と言い、画面にも「こう かんがえられて いる」と出している。
- 「水がどうやって神経を動かすのか」がまだ確かめられていないことは、長さの都合でナレーションに入れず、概要欄に書いた。
- 細胞がふくらむ数字（約50％）、つなぎなおした指の研究、しわができるまでの時間（2.1〜37分）は入れていない。
- 「ある実験」＝ニューカッスル大学（2013年）、「べつの実験」＝2014年の研究（40人）。
