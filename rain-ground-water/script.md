# あめの ゆくえ（雨のあとの地面の水） 台本

タイトル：雨がふったあと、地面の水はどこへ行くの？｜みのまわり図鑑 あめの ゆくえ
出どころ：everyday-trivia `trivia/rain-ground-water.md`（地面の水の行き先は3つ：土のすき間にしみこむ・高いところから低いところへ流れる・水蒸気になって空へもどる／土は小さな粒の集まりで、粒の間にすき間がある／粒の大きい砂はすき間が大きく水が速く通りぬけ、粒の小さい土はゆっくり／雨がしみこめる速さより速くふると、しみこみきれない水が低いところに集まって水たまりに／アスファルトにはしみこまず、道路はまん中が少し高く、端の溝から地下の管を通って川へ／水は沸とうしなくても水面や地面から蒸発する／地下水は速くても1日に10〜100メートルくらいで、川よりずっとゆっくり。わき水や川になって海へもどり、蒸発した水は雲になってまた雨に／みてみよう）／メモ `ideas/notes/rain-ground-water.md`
正解：2番（cast.py）／吹き出し：S → K → B（おわり S・B）
言い方の注意：場所ごとの答え（「砂場がいちばん早くかわく」など）は言わない。くらべるのは「粒の大きい砂」と「粒の細かい土」のしみこむ速さと、しみこまないアスファルト。地下水の速さは「速くても1日に10〜100メートルくらい」まで（何年で海に着く、とは言わない）。35％の数字、合流式下水道、鶴見川の話は入れない。「雨水」は読みまちがいをさけて「雨の水」、「地下の管」は「地面の下のパイプ」と言う（記事の見出しも「パイプを通って川へ」）。


## 1. つかみ（hook）
- N: 雨の日、校庭に、大きな水たまりができました。
- N: でも、雨がやんでしばらくすると、なくなっています。
- S（吹き出し）: みずたまり、きえちゃった！
- N: 雨がふったあと、地面の水は、どこへ行くんでしょう。

## 2. 予想（guess）
- N: 水がいちばん速くしみこむのは、どれ？ 予想してみよう。
- N: 1番。つぶの細かい、土の地面。
- N: 2番。つぶの大きい、砂場の砂。
- N: 3番。黒い、アスファルトの道。
- N: 答えをさがしに、雨の水のゆくえを追いかけてみましょう。

## 3. 行き先は3つ（しみこむ・流れる・空へもどる）（three）
- N: 地面にふった雨の行き先は、大きく分けて3つあります。
- N: 1つめは、土にしみこむ。
- N: 2つめは、高いところから低いところへ流れる。
- N: 3つめは、水蒸気になって、空へもどる。

## 4. しみこむ：土は粒の集まり。粒が大きいと速い（soak）
- N: まずは、しみこむ水。土は、小さなつぶの集まりです。
- N: つぶとつぶの間にはすき間があって、雨はそこにしみこみます。
- N: 砂のようにつぶが大きいと、すき間も大きいので、水は速く通りぬけます。
- N: つぶの細かい土は、すき間が小さいので、ゆっくりしかしみこみません。
- K（吹き出し）: すなは スーッ！

## 5. 流れる：のみきれない水は低いところへ集まって水たまりに（puddle）
- N: 雨が強いと、土が水をのみきれないことがあります。
- N: のみきれない水は、低いところへ流れて集まり、水たまりになります。

## 6. まちの雨：アスファルト → みぞ → パイプ → 川（street）
- N: まちの道のアスファルトには、水はしみこみません。
- N: 道路は、まん中が少し高くなっていて、雨の水は、はしのみぞへ流れます。
- N: そこから、地面の下のパイプを通って、川へ集まります。

## 7. 空へもどる：蒸発（sky）
- N: さいごは、空へもどる水です。
- N: 水は、ふっとうしなくても、水面や地面から蒸発して、水蒸気になります。
- N: 水たまりが小さくなったり、ぬれた地面がかわいたりするのは、このためです。
- B（吹き出し）: そらに かえったんだ！

## 8. 地下水はゆっくり → わき水・川 → 海 → 雲 → また雨（under）
- N: 土にしみこんだ水は、地下水になります。
- N: 地下水が進むのは、速くても、1日に10メートルから100メートルくらい。
- N: 川の水より、ずっとゆっくりです。
- N: やがて、わき水や川になって、海へもどります。
- N: 海や地面から蒸発した水は、雲になって、また雨としてふってきます。

## 9. 正解とみてみよう（look）
- N: 正解は2番。つぶの大きい砂は、すき間も大きいので、水が速くしみこむんだね。
- N: 雨がやんだ次の日に、砂場や土のグラウンド、アスファルトの道を見てみよう。
- N: どこに水たまりが残っているか、予想してから確かめてね。
- N: 雨の日に見るときは、歩道や家の中から。
- N: みぞのふたの穴に、手や棒を入れないでね。
- N: 雨でふえた川や用水路には、近づかないこと。
- N: 水たまりの水も、口に入れないでね。

## 10. おわり（end）
- S: またね！ / B: またねー！
