# さかなのえら 台本

タイトル：魚は、どうして水の中で息ができるの？｜みのまわり図鑑 さかな

もとの記事：everyday-trivia `trivia/fish-gills.md`（メモ：`ideas/notes/fish-gills.md`）

cast.py：正解は2番／吹き出しは S → B → K（おわりは S・B）

## 1. つかみ（金魚はずっと水の中。口をぱくぱく）
- N: 金魚は、ずっと水の中でくらしています。
- N: よく見ると、口をぱくぱく、動かしています。
- S（吹き出し）: なに してるの？
- N: 魚は、どうして水の中で息ができるんでしょう。

## 2. 予想（正解は2番）
- N: 予想してみよう。金魚の口のぱくぱくは、何をしているのかな？
- N: 1番。おなかがすいた、あいず。
- N: 2番。えらに水を通して、息をしている。
- N: 3番。あわを作っている。
- N: まずは、水の中を見てみましょう。

## 3. 水の中のさんそは、空気よりずっと少ない
- N: 水の中にも、息をするのにいる「さんそ」がとけています。
- N: でも、その量は、空気よりずっと少ないんです。
- N: 同じだけのさんそを取るには、空気の、およそ30倍の水がいります。
- N: だから魚は、たくさんの水を、えらに通しつづけます。

## 4. 口から入って、えらぶたから出る一方通行
- N: 人は、同じ口や鼻から、息をすったり、はいたりします。
- N: でも魚の水は、口から入って、頭の横の「えらぶた」のすきまから出ていきます。
- N: いつも同じ向きに流れる、一方通行です。
- N: 口がとじると、えらぶたがひらく。
- N: かわりばんこに動いて、水を送っているんです。
- B（吹き出し）: えらぶたが ひらいた！

## 5. えらの3段ズーム（赤いくし → ひだ → うすいかべ）
- N: えらぶたの下には、赤いくしのような「えら」がならんでいます。
- N: えらには、小さなひだが、ぎっしりならんでいます。
- N: 水にふれるところが、とても広くなっているんです。
- K（吹き出し）: ひだが ぎっしり！
- N: えらが赤いのは、うすいかべのすぐうらを、血が流れているから。
- N: 水の中のさんそは、このうすいかべを通って、血の中に入ります。

## 6. 血と水は反対向き／マグロ
- N: しかも、血と水は、反対向きに流れています。
- N: こうすると、同じ向きに流すより、さんそをたくさん取りこめるんです。
- N: えらを通る水のさんその、およそ4分の3を取りこめます。
- N: これは、人の肺の2倍のわりあいです。
- N: マグロのなかまは、口を少しあけたまま泳ぎつづけて、えらに水を通します。

## 7. 水から出ると、えらがしぼむ
- N: では、魚を水から出すと、どうなるでしょう。
- N: 空気には、さんそがたくさんあるのに、ほとんどの魚は息ができません。
- N: 水が流れないと、えらのひだがしぼんで、くっついてしまうからです。

## 8. 正解 と みてみよう
- N: 正解は2番。口のぱくぱくは、えらに水を通して、息をする動きだったんだね。
- N: 金魚やメダカの水そうを横から見て、口がとじたとき、えらぶたがひらくか見てみよう。
- N: 水族館でマグロを見たら、口が少しあいたまま泳いでいるか、見てみてね。
- N: 魚は、水から出さないでね。
- N: 水そうに手を入れたり、ガラスをたたいたりしないで、見るだけにしよう。

## 9. おわり
- S（吹き出し）: またね！
- B（吹き出し）: またねー！

## 絵のメモ
- 「40こ と 1こ」は、30℃の水と空気をくらべた数（FAO）。ナレーションでは数字を言わず、絵と概要欄に入れる。
- 「およそ30倍の水」はメトロポリタン州立大学デンバーの講義資料。
- 「4分の3（約75％）」「人の肺の2倍」はアメリカ自然史博物館。
- 「魚は水を飲まない」とは言わない。ぱくぱくは「息をする動き」。
- えらの数、1分に何回動くか、水から出して何分、は言わない。
- さんそのつぶ・ひだ・血のつぶの大きさや数は、見やすいように描く。
