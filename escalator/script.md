# エスカレーター 台本

## 1. つかみ（hook）
- N: エスカレーターに乗ると、足もとから、階段がつぎつぎに出てきます。
- N: 上に着くと、階段は床にすいこまれて、消えてしまいますね。
- S（吹き出し）: どこに いくの？
- N: 消えた階段は、そのあと、どこへ行くんでしょう。

## 2. 予想（guess）
- N: 消えた階段は、どこへ行くと思う？
- N: 1番。床の下で、小さくたたまれて、しまわれる。
- N: 2番。床の下で、とけて、新しい階段になる。
- N: 3番。床の下を通って、乗り口までもどる。
- N: 答えをさがしに、まずは、階段のつながり方を見てみましょう。

## 3. 段は大きな輪（loop）
- N: エスカレーターの段は、チェーンで、一列につながっています。
- N: ぐるっと、大きな輪になっているんです。
- N: 上のはしの中には、モーターがあって、歯車を回して、この輪を動かしています。
- B（吹き出し）: ぐるぐる！

## 4. 裏がわを通ってもどる（return）
- N: 上まで運ばれた段は、はしで、くるっと向きを変えます。
- N: そして、床の下の、裏がわのレールを通って、下へもどっていきます。
- N: 下に着いたら、また向きを変えて、乗り口から出てくるんです。

## 5. くしとみぞ（comb）
- N: 降り口の床のはしを、よく見てみましょう。くしのような、ぎざぎざがあります。
- N: 段の上には、細いみぞがあって、くしの歯が、みぞの中に入りこんでいます。
- N: 段はくしの下にもぐっていきますが、足や靴は、くしの上に乗りあげるんです。
- N: くしの先を、なだらかな坂にして、引っかかりにくくしているものもあります。

## 6. 階段になるしくみ（wheel）
- N: では、どうして、乗り口では平らなのに、とちゅうから階段になるんでしょう。
- N: ひとつの段には、前の車輪と、後ろの車輪がついていて、べつべつのレールの上を走ります。
- N: 2本のレールの高さの差を変えて、段は、いつも水平のまま。
- N: まんなかでは段差ができて階段に、乗り口と降り口では、平らにならぶんです。
- S（吹き出し）: かいだんに なった！

## 7. おまけ 速さとかたむき（speed）
- N: おまけ。ふつうのエスカレーターは、1分間に、30メートル進みます。
- N: かたむきは、ふつう30度です。

## 8. 正解とみてみよう（look）
- N: 正解は3番。床の下を通って、乗り口までもどっていたんだね。
- N: 乗る前に、少し手前で立ち止まって、横から見てみよう。
- N: 平らな段が、何枚出てきてから、階段になるかな。1枚半くらい？3枚？
- N: 見るときは、人の流れの、じゃまにならない場所でね。
- N: 乗るときは、黄色い線の内がわに立とう。
- N: くしのところには手をふれず、落とし物をしたら、係の人をよんでね。

## 9. おわり（end）
- S（吹き出し）: またね！
- B（吹き出し）: またねー！
