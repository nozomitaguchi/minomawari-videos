# でんしゃの しゃりん 台本（案）

タイトル：電車は、どうやって カーブを 曲がるの？｜みのまわり図鑑 でんしゃ

元記事：everyday-trivia `trivia/train-wheel-curve.md`
正解は2番（cast.py）。吹き出しは S → B → K（cast.py）。


## 1. つかみ（カーブを曲がる電車）
- N: 電車が、カーブを曲がっていきます。
- N: 線路がぐーっと曲がっていても、電車は、すいすい進みます。
- S（吹き出し）: すいすい まがるね！
- N: 電車は、どうやって、カーブを曲がっているんでしょう。

## 2. 予想
- N: どうやってだと思う？ 予想してみよう。
- N: 1番。運転士さんが、ハンドルで曲げている。
- N: 2番。車輪が、ななめの形になっている。
- N: 3番。外がわの車輪だけ、速く回っている。
- N: 答えをさがしに、まずは、カーブの線路を見てみましょう。

## 3. カーブでは、外がわのレールのほうが長い
- N: カーブの線路には、外がわのレールと、内がわのレールがあります。
- N: くらべてみると、外がわのレールのほうが、長くなっています。
- N: だから、外がわの車輪は、内がわの車輪より、たくさん進まないといけません。

## 4. 車輪は右と左がつながっている
- N: ところが、電車の車輪は、右と左が、1本のじくで、がっちりつながっています。
- N: だから、右も左も、同じだけしか回れません。
- B（吹き出し）: いっしょに くるくる！
- N: それなのに、電車は、カーブを曲がっていきます。

## 5. ひみつは車輪の形（外がわほど細い）
- N: ひみつは、車輪の形にあります。
- N: レールにのる面は、平らではなく、外がわに向かって、少し細くなっているんです。

## 6. カーブでは外がわへずれる
- N: カーブに入ると、車輪は、外がわへ少しずれます。
- N: すると、外の車輪は太いところ、内の車輪は細いところで、レールにのります。

## 7. 太いところのほうが長く進む → 自然に曲がる
- N: 同じ1回転でも、太いところのほうが、長く進みます。
- N: だから車輪は、自然に、カーブの内がわへ向きを変えるんです。

## 8. 紙コップを転がすと
- N: 紙コップを横にして、そっと転がしてみましょう。
- N: まっすぐには進まず、細いほうへ、ぐるっと曲がっていきます。
- N: 車輪のななめの形も、これと同じ考え方です。
- K（吹き出し）: おなじだ〜

## 9. つば（フランジ）
- N: 車輪の内がわのはしには、「つば」という出っぱりがあります。
- N: 急なカーブでは、つばがレールの横に当たって、車輪を案内します。
- N: 車輪がレールから外れるのを、ふせいでいるんです。

## 10. まっすぐではくねくね → 新幹線はななめが小さい
- N: でも、ななめの車輪は、まっすぐな線路で、左右にくねくねと首をふります。
- N: そこで、速く走る新幹線は、車輪のななめを、小さくしているんです。

## 11. 正解とみてみよう
- N: 正解は2番。車輪がななめの形だから、電車は自然に、カーブを曲がれるんだね。
- N: 駅のホームから、止まっている電車の車輪を見てみよう。
- N: レールにのる面が、外に向かって細くなっているか、内がわにつばがあるか、さがしてみよう。
- N: 電車が動くときは、ホームのはしからはなれて、黄色い線の内がわから見てね。
- N: おうちでは、紙コップを転がして、どっちに曲がるか、ためしてみよう。

## 12. おわり
- S: またね！ / B: またねー！
