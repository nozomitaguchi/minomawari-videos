# お月さまがついてくる 台本

タイトル：車に乗ると、どうして お月さまが ついてくるの？｜みのまわり図鑑 おつきさま

もとの記事：everyday-trivia `trivia/moon-follows-car.md`（メモ：`ideas/notes/moon-follows-car.md`）

cast.py：正解は3番／吹き出しは S → B → K（おわりは S・B）

## 1. つかみ（夜の車のまど。木や電柱は流れるのに、月だけ同じところ）
- N: 夜、車のまどから、外を見ています。
- N: 道ばたの木や電柱は、どんどんうしろへ流れていきます。
- N: でも、お月さまだけは、ずっと同じところにいます。
- S（吹き出し）: おつきさま、ついて くる！
- N: 車に乗ると、どうしてお月さまは、ついてくるんでしょう。

## 2. 予想（正解は3番）
- N: どうしてだと思う？ 予想してみよう。
- N: 1番。お月さまが、車を追いかけている。
- N: 2番。車のまどに、お月さまがうつっている。
- N: 3番。お月さまが、とても遠くにある。
- N: まずは、まどの外を、よく見てみましょう。

## 3. まどから：近いものは「びゅーん」、遠いものは「ゆっくり」（3層のスクロール）
- N: まどのすぐそばの木やさくは、びゅーんと、うしろへ流れていきます。
- B（吹き出し）: きが びゅーん！
- N: でも、遠くの家や山は、ゆっくりしか動きません。
- N: 近いものほど速く、遠いものほどゆっくり、流れて見えるんです。

## 4. 上から見た図：近い木は見える向きが大きく変わり、遠い山は少ししか変わらない
- N: どうしてでしょう。車を、上から見てみます。
- N: 同じだけ進んでも、近くの木は、見える向きが大きく変わります。
- N: 遠くの山は、見える向きが、少ししか変わりません。

## 5. 指でためす（近い指と、うでをのばした先の指）
- N: 指でも、ためせます。人さし指を、顔のすぐ前と、うでをのばした先に立てます。
- N: 頭を左右に動かすと、近い指のほうが、ずっと速く動いて見えます。
- K（吹き出し）: ちかい ゆびが はやい！

## 6. 月はけたちがいに遠い（約38万km、時速100kmで半年近く、1kmは38万分の1）
- N: では、お月さまは、どのくらい遠いのでしょう。
- N: 地球からお月さままでは、およそ38万キロメートル。
- N: 時速100キロの車で、休まず走りつづけても、半年近くかかる遠さです。
- N: 車で1キロ走っても、お月さままでの、38万分の1にしかなりません。

## 7. だから月の見える向きは変わらない → まわりが流れるのに月だけ同じところ → ついてくるように感じる（思いちがい）
- N: だから、車がどんなに走っても、お月さまの見える向きは、ほとんど変わりません。
- N: まわりはうしろへ流れるのに、お月さまだけが、まどの同じところに見えます。
- N: それで、いっしょについてくるように、感じるんです。
- N: 本当に追いかけているのではなく、目や頭の、思いちがいなんですね。
- N: お月さまは、夜空で大きく明るく目立つので、よけいに気になるのかもしれません。

## 8. 何時間も見ていると月は動く（東→南→西。地球が回っているから）
- N: ただし、何時間も見ていると、お月さまも動きます。
- N: 東からのぼって、南の空を通り、西へしずんでいきます。
- N: これは、車が走るからではなく、地球が回っているからです。

## 9. 正解と、みてみよう（電柱・山・月を見くらべる。顔や手を出さない・シートベルト・運転のじゃまをしない）
- N: 正解は3番。お月さまが、とても遠くにあるから、ついてくるように見えたんだね。
- N: 大人の運転する車や電車に乗ったら、近くの電柱、遠くの山、お月さまを、見くらべてみよう。
- N: どれがいちばん速く、うしろへ流れるかな。
- N: まどから、顔や手は、出さないでね。
- N: シートベルトをして、運転している人の、じゃまをしないようにしよう。

## 10. おわり
- S: またね！ / B: またねー！

## 言いかたの注意（メモから）
- 「月が動かない」とは言い切らない（「見える向きは、ほとんど変わらない」。何時間もたつと東から西へ動く）
- 太陽や星もついてくる・車が曲がると別の窓に移る、は言わない。心理学の研究の話、月の見かけの大きさの話もしない
- 数字は 約38万km／時速100kmで休まず走って約160日（半年近く）／1kmは38万分の1／指は顔から約8cm まで
