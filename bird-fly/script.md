# 鳥が飛ぶしくみ 台本

タイトル：鳥は、どうして空を飛べるの？｜みのまわり図鑑 とり

もとの記事：everyday-trivia `trivia/bird-flight.md`（メモ：`ideas/notes/bird-fly.md`）

cast.py：正解は3番／吹き出しは S → K → B（おわりは S・B）

## 1. つかみ（ハトがバタバタ飛び立つ）
- N: 公園のハトが、バタバタと飛び立ちました。
- N: つばさを大きく上げては、強く打ちおろしています。
- S（吹き出し）: バタバタ いってる！
- N: 鳥は、どうして空を飛べるんでしょう。

## 2. 予想（正解は3番）
- N: 予想してみよう。つばさを上げるとき、さきの羽根は、どうなるかな？
- N: 1番。ぴったり、くっついたまま。
- N: 2番。くるんと、まるまる。
- N: 3番。あいだに、すきまがあく。
- N: まずは、飛ぶしくみを見ていきましょう。

## 3. つばさで空気を下と後ろへ押す。上と下で押す力がちがう
- N: 鳥は、つばさで空気を、下と後ろへ押しています。
- N: すると、体が持ち上がって、前へ進むんです。
- N: つばさの上は、まるくふくらんでいて、上を通る空気は、押す力が弱くなります。
- N: 下から押す力のほうが強いので、体が持ち上がるんです。

## 4. つばさは腕と手。羽根がならんで面になる。羽根はマジックテープ
- N: つばさは、人の腕と手にあたるところが、変わったものです。
- N: そこに長い羽根がならんで、空気を受ける面になっています。
- N: 羽根には小さなかぎがたくさんあって、マジックテープのようにくっついています。
- K（吹き出し）: かぎが いっぱい！
- N: 鳥は、くちばしで羽根をととのえて、かぎをしっかりかみ合わせます。

## 5. 打ちおろしで重なり、打ち上げですきまが開く（いちばんの見せ場）
- N: つばさを打ちおろすとき、さきの羽根は重なり合って、前へ進む力を生みます。
- N: つばさを上げるときは、さきの羽根が、ブラインドのように開きます。
- B（吹き出し）: すきまが あいた！
- N: すきまを空気がすりぬけるので、空気にじゃまされにくくなるんです。

## 6. 胸の大きな筋肉と出っぱり。体の5分の1。上げる筋肉も胸にあって滑車で引き上げる
- N: つばさを動かすのは、胸の大きな筋肉です。
- N: 胸の骨には、筋肉がつく、大きな出っぱりがあります。
- N: その筋肉は、合わせて体の重さの5分の1ほど。人の胸の筋肉は、200分の1ほどです。
- N: つばさを上げる筋肉も、背中ではなく胸にあります。
- N: 長いすじを肩のあなに通して、滑車のように引き上げるんです。

## 7. 骨は中が空っぽ。でも軽すぎるわけではない
- N: 鳥の骨は、中が空っぽのものもあります。
- N: でも、軽すぎるわけではありません。ぎゅっとつまった、かたくて強い骨です。
- N: 小鳥の骨の重さは、同じ重さのネズミのなかまと、同じくらいなんです。

## 8. はばたかずに、くるくるのぼる鳥
- N: 空の高いところには、はばたかずに輪をかく、大きな鳥もいます。
- N: のぼっていくあたたかい空気の柱の中を、くるくる回っているんです。

## 9. 正解 と みてみよう
- N: 正解は3番。つばさを上げるときは、羽根のあいだに、すきまがあくんだね。
- N: 公園でハトを見つけたら、はなれたところから見てみよう。
- N: 飛び立つときと、飛んでからの、つばさの動きをくらべてみてね。
- N: ハトには近づかないで。追いかけるのも、やめようね。
- N: 空の鳥をさがすときは、太陽を、ぜったいに直接見ないでね。

## 10. おわり
- S（吹き出し）: またね！
- B（吹き出し）: またねー！

## 絵のメモ
- 色の約束：とり＝はいいろ（ハト）、くうき＝あおい やじるし、うく・すすむ＝みどりの やじるし、むねの きんにく＝あか、つばさを あげる きんにく＝ピンク、ほね＝うすき、あたたかい くうき＝オレンジ。
- 「骨が軽いから飛べる」とは言わない。「からっぽの ものも ある。でも かるすぎない。ぎゅっと つまって かたい」（デュモン 2010）。約57グラムの小鳥とネズミのなかまの骨格が同じくらい、の数字は絵と概要欄だけ。
- すきまが開く理由は「空気の抵抗を小さくするため」（ミネソタ州天然資源局）まで。「すきまがあるから浮く」とは言わない。
- 「5分の1」は、いろいろな鳥の平均（大胸筋17％＋烏口上筋2〜4％＝約20％、ビューウェナー 2022）。「どの鳥も」とは言わない。人の大胸筋は約0.5％（200分の1）。絵は100個のしかくで、鳥は20個、人は半分。
- 揚力は「上は押す力が弱く、下は強い」まで（飛行機の回と同じ考え方、は絵のバッジで）。「上と下の空気が同時に後ろで出会う」は言わない。
- 輪をかく鳥は、資料ではコンドル・ハゲワシのなかまと一部のタカ。トビとは名指ししない。絵では「おおきな とり」とだけ書く。
- 打ちおろしで「前へ進む力を生む」は資料どおり（初列風切が重なり合って推力を生む）。
- 羽根・かぎ・骨の中・筋肉は、見やすいように大きく、かんたんな形で描く。
