# 鏡 台本

タイトル：鏡は、本当に左右を反対にする？｜みのまわり図鑑 鏡
出どころ：everyday-trivia `trivia/mirror-left-right.md`・`mirror-basics.md`

## 1. つかみ（hook）
- N: 鏡の前に立つと、もう一人の自分がいます。
- N: 右手を上げると、鏡の中の人は、左手を上げているように見えます。
- S（吹き出し）: はんたいだ！
- N: 鏡は、本当に左右を反対にしているんでしょうか。

## 2. 予想（guess）
- N: 鏡が本当に反対にしているのは、どれだと思う？
- N: 1番。右と左。
- N: 2番。上と下。
- N: 3番。前と後ろ。
- N: 答えをさがしに、まずは、鏡がどうして映るのか、見てみましょう。

## 3. そろえてはね返す（reflect）
- N: ものが見えるのは、光がはね返って、目に入るからです。
- N: 白い紙は、光をあらゆる向きに、ばらばらにはね返します。
- N: とても平らな鏡は、光を決まった向きに、そろえてはね返します。
- N: だから、顔の形がくずれずに、目に届くんです。
- N: はね返る角度は、入ってくる角度と同じです。

## 4. 鏡の奥（behind）
- N: 鏡の中の顔は、鏡の奥にあるように見えます。
- N: 自分が鏡の前にいるのと、同じだけ離れたところです。
- N: だから、全身を映すのに要る鏡は、身長の半分の高さでいいんです。

## 5. 反対なのは前と後ろ（check）
- N: では、右手を上げてみましょう。
- N: 鏡の中でも、右側の手が上がっています。
- N: 頭は上に、足は下に映ります。
- N: 鏡に向かって指さすと、鏡の中の指は、こちらを指します。
- N: 鏡が反対にしているのは、じつは「前と後ろ」なんです。
- K（吹き出し）: まえと うしろ！

## 6. どうして左右が反対に見える？（why）
- N: では、どうして左右が反対に見えるのかな。
- N: それは、鏡の中の人の立場になって、「その人の右手はどっち？」と考えるからです。
- N: 自分の向きのまま見れば、右手は右側にあります。
- N: 東京大学の高野陽太郎さんの実験では、鏡の中の自分を、左右反対だと感じない人が、2割から4割いました。

## 7. 文字と救急車（letters）
- N: でも、鏡に映した文字は、みんなが、左右反対だと感じます。
- N: 鏡に映したように、左右が逆になった字を、「鏡文字」といいます。
- N: 救急車の前に、反対向きの「急救」と書いてある町があります。
- N: 前の車がミラーで見ると、ふつうの「救急」と読めるからです。
- B（吹き出し）: よめた！

## 8. 正解とみてみよう（look）
- N: 正解は3番。鏡が反対にしていたのは、前と後ろだったんだね。
- N: 自分の名前を書いた紙を、鏡に向けてみよう。
- N: 横に回したときと、上下にひっくり返したときで、鏡の中の字がどうちがうか、予想してから見てね。
- N: 救急車は、止まっているときや写真で見て、道路では近づかないでね。

## 9. おわり（end）
- S: またね！ / B: またねー！
