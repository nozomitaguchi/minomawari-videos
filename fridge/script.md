# れいぞうこ 台本

タイトル：冷蔵庫は中を冷やしているのに、どうして外があったかいの？｜みのまわり図鑑 れいぞうこ
出どころ：everyday-trivia `trivia/fridge-warm-outside.md`（冷蔵庫の中は冷たいのに、大人が横の面にさわるとほんのり温かい・冷蔵庫は冷たさを「作って」いるのではなく、中にある熱を、管の中をめぐる冷媒に運ばせて外へ出している（ダンフォス・パナソニック）・冷媒は液体から気体に変わるときにまわりの温度をうばう。プールから上がると体がひんやりするのと同じ（家電 Watch）・冷媒は4つの部品を順番にめぐる：冷却器（中にあり、液体の冷媒が気体になるときにまわりを冷やす）→ 圧縮機（気体の冷媒に圧力をかけて熱くする）→ 放熱する部品（熱をまわりの空気へ出す。うしろ・両側の面など、場所は機種によってちがう）→ 細い管（通った冷媒はまた冷却器へもどる）（ダンフォスほか）・アイリスオーヤマの冷凍冷蔵庫は側面に放熱パイプがあり、まわりが30℃のとき50℃以上になる場合がある。一度に食べものをたくさん入れたとき、ドアの開け閉めが多いときには、中を冷やすためにたくさん放熱する。中を冷やすほど外は温かくなる・冷蔵庫を動かすモーターの電気も一部が熱になるので、外へ捨てる熱は中からくみ出した熱より多い（イリノイ大学・OpenStax）・ドアを開けっぱなしにしても部屋は涼しくならず、温度は上がる（OpenStax・PhysLink）・左右とうしろに放熱のためのすき間をあけて置く。熱がこもらないようにするため。必要なすき間は製品によってちがう（アイリスオーヤマ・日立）・みてみよう：冷蔵庫の横の面と部屋の壁、どちらが温かいか予想してから、大人にそっとさわってもらってくらべる。うしろや下の機械のあたりは熱くなることがあるので、子どもは手を入れない・さわらない。上と横にすき間があるかを見る。ドアは開けたら手早く閉める）／`ideas/notes/fridge.md`（見せ場・場面の順番・注意書き）

言い方の注意：冷媒は読みまちがいをさけるため、ナレーションではひらがなで「れいばい」と書く。「50度以上」は「まわりが30度のとき、50度以上になる冷蔵庫もあります」と言い、どの冷蔵庫でもいつも50度とは言わない（アイリスオーヤマの冷凍冷蔵庫の話。概要欄の注に書く）。熱を出す管の場所は機種でちがうので「横やうしろ」と言い、「かならず横」とは言わない。「ドアを開けると冷たい空気が下からこぼれる」は確かめていないので言わない（絵では、開けたドアの前に、冷たい空気の小さな線を少し出すだけ）。冷凍室と冷蔵室のちがい・ダンパー・霜取り・蒸発皿・省エネの数字（kWh）は入れない（時間の都合）。冷蔵庫を切った絵・管の位置や太さ・熱のつぶの数（4＋2＝6）は、わかりやすくした絵で、本物の比率ではない。温度計の絵の目もりもイメージ。


## 1. つかみ（hook）
- N: 冷蔵庫の中は、ひんやり冷たい。
- N: それなのに、大人が冷蔵庫の横にさわると、ほんのりあたたかいんです。
- S（吹き出し）: なかは つめたいのに？
- N: 中を冷やしているのに、どうして外が、あたたかいんでしょう。

## 2. 予想（guess）
- N: どうしてだと思う？ 予想してみよう。
- N: 1番。中のライトが、熱くなっているから。
- N: 2番。中の熱を、外へ運び出しているから。
- N: 3番。冷蔵庫が、こわれかけているから。
- N: 冷蔵庫の中で、何が起きているのか、見てみましょう。

## 3. 冷たさを作るのではなく、中の熱を外へ運ぶ（carry）
- N: じつは冷蔵庫は、冷たさを作っているのではありません。
- N: 中にある熱を、外へ運び出している機械なんです。
- N: 熱を運ぶのは、管の中をめぐる、「れいばい」という運び役。

## 4. 液体から気体に変わるとき、まわりの熱をうばう（evap）
- N: れいばいは、液体から気体に変わるとき、まわりの熱をうばいます。
- N: プールから上がると、体がひんやりするのと、同じです。
- B（吹き出し）: ひんやり する！

## 5. れいばいは、4つの部品をぐるぐるめぐる（cycle）
- N: れいばいは、4つの部品を、ぐるぐるめぐります。
- N: まず、冷蔵庫の中にある冷却器。液体のれいばいが気体になって、中を冷やします。
- N: つぎは圧縮機。気体のれいばいを、ぎゅっと押しちぢめて、熱くします。
- N: 熱くなったれいばいは、横やうしろの管で、熱を部屋へ出します。
- N: さいごに細い管を通って、また冷却器へもどります。

## 6. だから横やうしろはあたたかい・50度以上になることも（side）
- N: だから、冷蔵庫の横やうしろは、あたたかいんです。
- N: まわりが30度のとき、横の面が50度以上になる冷蔵庫もあります。
- S（吹き出し）: そんなに あついの！
- N: 中をたくさん冷やすほど、外はあたたかくなります。

## 7. 外へ出す熱＝中の熱＋モーターの分。ドアを開けっぱなしでもすずしくならない（balance）
- N: しかも、冷蔵庫を動かすモーターの電気も、一部が熱になります。
- N: だから、外へ出す熱は、中から運んだ熱より、多いんです。
- N: ドアを開けっぱなしにしても、部屋はすずしくなりません。
- N: かえって、あたたかくなってしまいます。

## 8. 熱がこもらないように、すきまをあける（gap）
- N: 熱がこもらないように、冷蔵庫のまわりには、すきまをあけて置きます。

## 9. 正解とみてみよう（look）
- N: 正解は2番。中の熱を、外へ運び出していたんだね。
- N: 冷蔵庫の横と、部屋のかべ。どっちがあたたかいか、予想してみよう。
- N: それから大人に、そっとさわってもらって、くらべてみよう。
- N: 冷蔵庫の上や横に、すきまがあるかも、見てみよう。
- N: うしろや下の機械は、熱くなることがあるので、手を入れないでね。
- N: ドアは、開けたら、すぐ閉めようね。

## 10. おわり（end）
- S（吹き出し）: またね！
- B（吹き出し）: またねー！
