# なみだ 台本

タイトル：泣くと、どうして鼻水まで出るの？｜みのまわり図鑑 なみだ
出どころ：everyday-trivia `trivia/eye-tears-blink.md`
正解：1番（cast.py）／吹き出し：S → B → K


## 1. つかみ（hook）
- N: えーん、えーん。いっぱい泣いていると、
- N: なみだといっしょに、鼻水まで出てきます。
- S（吹き出し）: なんで はなみずまで？
- N: なみだは目から出るのに、どうして鼻から出るんでしょう。

## 2. 予想（guess）
- N: 泣いたときの鼻水は、何だと思う？
- N: 1番。目から鼻へ、流れこんだなみだ。
- N: 2番。悲しくなると、鼻も鼻水を作る。
- N: 3番。大きな声を出すと、のどから水が上がってくる。
- N: 答えをさがしに、なみだの通り道を、たどってみましょう。

## 3. なみだはいつも（always）
- N: じつは、なみだは、泣いていないときも出ています。
- N: 目の表面は、いつも、うすいなみだの膜でおおわれているんです。

## 4. 涙腺（gland）
- N: なみだが生まれるのは、目じりの上のほう。
- N: 「涙腺」というところで、作られます。

## 5. まばたき（blink）
- N: まばたきをすると、なみだが、目の表面全体に広がります。
- N: 目の表面の小さなごみも、いっしょに流してくれます。
- N: まばたきは、1分に15回から20回くらいしています。

## 6. 涙点（punctum）
- N: 広がったなみだは、目の表面を、鼻のほうへ流れていきます。
- N: 目がしらの、上と下のまぶたのふちには、小さな穴が1つずつあります。
- B（吹き出し）: ちっちゃい あな！
- N: これが「涙点」。なみだの、すいこみ口です。

## 7. 鼻へ（nose）
- N: 涙点に入ったなみだは、細い管を通って、鼻の中へ流れていきます。
- N: 目と鼻は、この管で、つながっているんです。
- N: ふだんは、鼻の中で、かわいたり、体にすいもどされたりします。

## 8. 3つの種類（kinds）
- N: なみだには、3つの種類があります。
- N: いつも目をうるおして守る、ふだんのなみだ。
- N: ごみやけむり、たまねぎのしげきを、洗い流すなみだ。
- N: うれしい、悲しい、こわい。気持ちが動いたときのなみだ。

## 9. 泣くと（cry）
- N: 悲しいときや、目にごみが入ったときは、なみだがたくさん作られます。
- N: すると、鼻へ流す道が、追いつかなくなります。
- N: あふれたなみだは、ほおを流れていきます。
- K（吹き出し）: あふれちゃった〜
- N: そして、鼻へ流れこんだぶんが、鼻から出てくるんです。

## 10. 正解とみてみよう（look）
- N: 正解は1番。泣いたときの鼻水の多くは、なみだだったんだね。
- N: 鏡で、自分の目がしらを見てみよう。
- N: 下のまぶたのふちの、鼻に近いところに、小さな点のような穴があるかな。
- N: 上のまぶたにもあるので、上と下の両方をさがしてね。
- N: まぶたを指で引っぱったり、さわったりは、しないでね。

## 11. おわり（end）
- S（吹き出し）: またね！
- B（吹き出し）: またねー！
