# 月 台本

タイトル：月は、どうして形が変わる？｜みのまわり図鑑 月
出どころ：everyday-trivia `trivia/moon-phases.md`・`moon-basics.md`・`moon-daytime.md`

## 1. つかみ（hook）
- N: 細い、三日月。
- N: まんまるの、満月。
- N: 月は、日によって、形が変わって見えます。
- S（吹き出し）: きょうは どんな かたち？
- N: どうして、形が変わるんでしょう。

## 2. 予想（guess）
- N: 月の形が変わるのは、どうしてだと思う？
- N: 1番。地球の影が、月にかかるから。
- N: 2番。太陽に照らされた面の、見え方が変わるから。
- N: 3番。月が、少しずつけずれて、また大きくなるから。
- N: 答えをさがしに、宇宙から、月を見てみましょう。

## 3. 月は光らない（light）
- N: 月は、自分では光りません。
- N: 太陽の光をはね返して、光っています。
- N: だから、太陽のほうを向いた半分が、いつも明るいんです。

## 4. 地球のまわりを回る（orbit）
- N: そして月は、地球のまわりを回っています。
- N: 1周するのに、27日と少しかかります。
- N: 回るにつれて、太陽と、地球と、月のならび方が、変わっていきます。

## 5. 見え方が変わる（phases）
- N: 月が、太陽と同じほうにあるとき、明るい面は向こうを向いていて、見えません。新月です。
- N: 太陽と直角のほうにあるときは、明るい面の半分が見えて、半月。
- N: 太陽と反対のほうにあるときは、明るい面がまるごと見えて、満月になります。
- B（吹き出し）: まんまる！

## 6. 29.5日（cycle）
- N: 新月から、次の新月までは、約29.5日。
- N: 1周より2日ほど長いのは、そのあいだに、地球も太陽のまわりを進んでいるからです。

## 7. 影じゃない（shadow）
- N: ちなみに、地球の影で欠けるのでは、ありません。
- N: 地球の影に月が入るのは「月食」といって、別のしくみです。
- N: 満ち欠けでは、欠けぎわのカーブが毎日変わり、半月では、まっすぐになります。
- K（吹き出し）: かげじゃ ない！

## 8. 光る側（side）
- N: 月の光っている側は、いつも太陽のほうを向いています。
- N: 夕方の三日月や半月は、太陽が沈んだ西のほうが、光っています。

## 9. 昼の月（day）
- N: 半月は、昼ごろ東からのぼるので、午後の青空にも見えます。
- N: 月は、昼の空にいる時間も、夜とほとんど同じくらいあるんです。

## 10. 正解とみてみよう（look）
- N: 正解は2番。太陽に照らされた面の、見え方が変わっていたんだね。
- N: 月を見つけたら、光っている側がどっちを向いているか、予想してから見てみよう。
- N: 半月なら、欠けぎわがまっすぐかも、見てみよう。
- N: 太陽は、ぜったいに直接見ないでね。

## 11. おわり（end）
- S: またね！ / B: またねー！
