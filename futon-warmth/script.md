# ふとん 台本

タイトル：おふとんは、どうして入ったときは冷たいのに、だんだんあったかくなるの？｜みのまわり図鑑 ふとん
出どころ：everyday-trivia `trivia/futon-warmth.md`（ふとんは自分で熱を出さない・入る前は部屋と同じ温度・体の熱で少しずつあたたまる・体に近いところほど速い・動かない空気・空気は動くと熱を運ぶ・わたの繊維が小さな部屋に分ける・家のかべの断熱材も同じ・ダウンはたんぽぽのわた毛の形・湿気は下の敷きぶとんへ・つぶれると空気がへる・みてみよう）／`trivia/futon-basics.md`（熱を出しているのは体・掛けぶとんは熱を逃がさない）／`trivia/futon-drying.md`（干すと湿気がぬけてふくらむ）
正解：1番（cast.py）／吹き出し：B → S → K（おわり S・B）


## 1. つかみ（hook）
- N: 寒い夜、おふとんに入ると、ひやっ。つめたい！
- B（吹き出し）: つめたーい！
- N: でも、しばらくすると、ぽかぽか、あったかくなってきます。
- N: おふとんは、どうして、だんだんあったかくなるんでしょう。

## 2. 予想（guess）
- N: どうしてだと思う？ 予想してみよう。
- N: 1番。体の熱が、ふとんの中にたまるから。
- N: 2番。ふとんが、自分で熱を出すから。
- N: 3番。ふとんが、部屋のあたたかさをすいこむから。
- N: 答えをさがしに、まずは、入る前のふとんを見てみましょう。

## 3. 入る前のふとんは、部屋と同じ温度（before）
- N: ふとんは、自分で熱を出しません。
- N: だから、入る前のふとんは、部屋と同じ温度。寒い部屋では、ふとんもつめたいんです。
- N: では、あたたかさは、どこから来るのでしょう。

## 4. 熱を出しているのは体（heater）
- N: 答えは、あなたの体。体が、熱を出しているんです。
- S（吹き出し）: わたしが ストーブ！
- N: ふとんに入ると、体の熱で、ふとんが少しずつあたたまっていきます。
- N: はじめは、体に近いところほど、はやくあたたまるんです。

## 5. ふとんは熱をにがしにくくする（keep）
- N: でも、体の熱は、そのままだと、まわりへにげていきます。
- N: ふとんは、その熱を、にがしにくくしているんです。

## 6. 動かない空気（air）
- N: 熱を止めているのは、わたのすき間にある、空気です。
- N: 空気は、熱をとても伝えにくいんです。
- N: でも、空気は、動くと熱を運んでしまいます。
- N: そこで、わたの細い糸が、空気を小さな部屋に分けて、動けなくしています。
- N: 熱を守っているのは、この「動かない空気」なんです。
- K（吹き出し）: じっと しててね〜

## 7. 家のかべとダウンも同じしくみ（same）
- N: 家のかべに入っている断熱材も、同じしくみです。
- N: 細い糸がからみ合って、動きにくい空気をとじこめています。
- N: 羽毛ふとんのダウンは、たんぽぽのわた毛のような形。軽いのに、空気をたっぷりかかえます。

## 8. ぺちゃんこのふとんは寒い（flat）
- N: ねている間、体からは、あせや湿気も出ています。
- N: 湿気は、下の敷きぶとんへ、たまっていきます。
- N: 湿ってつぶれると、中の空気がへって、あたたかさも落ちてしまいます。
- N: ぺちゃんこのふとんが寒いのは、空気が少ないからなんです。
- N: ふとんを干すと、湿気がぬけて、またふくらみます。

## 9. 正解とみてみよう（look）
- N: 正解は1番。体の熱が、ふとんの中にたまっていたんだね。
- N: おうちの敷きぶとんを、横から、目の高さで見てみよう。
- N: いつも背中やおしりがのるまん中と、はしの厚みをくらべます。
- N: どっちがうすいか、予想してから見てね。うすいところほど、空気が少なくなっているよ。

## 10. おわり（end）
