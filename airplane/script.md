# ひこうき 台本（案）

タイトル：飛行機は、あんなに重いのに、どうして空を飛べるの？｜みのまわり図鑑 ひこうき

## 1. つかみ（空港。重い飛行機が、走って、ふわっと浮く）
- N: 空港で見る飛行機は、人や荷物をのせると、とても重くなります。
- N: それなのに、滑走路を走ると、ふわっと浮き上がります。
- B（吹き出し）: おもいのに ういた！
- N: 飛行機は、あんなに重いのに、どうして空を飛べるんでしょう。

## 2. 予想
- N: 予想してみよう。重い飛行機を、空へ持ち上げているのは、何かな？
- N: 1番。エンジンが、下へ風をふき出している。
- N: 2番。つばさが、空気を下へ曲げている。
- N: 3番。中に、空気より軽いガスが入っている。
- N: まずは、飛行機の重さから見てみましょう。

## 3. 旅客機は、どのくらい重い？
- N: 旅客機のボーイング787は、いちばん重いとき、およそ255トンもあります。
- N: 人は、290人も乗れます。

## 4. 4つの力（持ち上げるのは、つばさ）
- N: 飛んでいる飛行機には、4つの力がはたらいています。
- N: 下へ引っぱる「重さ」と、上へ持ち上げる力。
- N: 前へ進める力と、後ろへ引きもどす、空気のていこうです。
- N: 前へ進めるのはエンジン。持ち上げているのは、つばさです。
- S（吹き出し）: エンジンじゃ ないんだ！

## 5. 浮くには、空気と速さがいる
- N: でも、止まっていると、持ち上げる力は生まれません。
- N: つばさのまわりを、空気が流れることが必要なんです。
- N: だから飛行機は、滑走路を走って、時速270キロまで速さを上げます。
- N: 持ち上げる力が、重さを上回ったとき、はじめて浮き上がります。

## 6. つばさは、空気を下へ曲げている（答えの場面）
- N: つばさは、前から来た空気を、下向きに曲げています。
- N: 空気を下へ押すと、その反動で、つばさは上へ押し返されます。
- N: このとき、つばさの上は空気の押す力が弱く、下は強くなっています。
- N: 下から上へ、ぐっと押し上げられるんです。
- N: この2つは、同じことを、別の側から見た説明です。

## 7. よくあるまちがい（煙の実験。紙飛行機）
- N: 「上と下に分かれた空気が、後ろで同時に出会う」という説明を、聞いたことがあるかもしれません。
- N: でも、これはまちがいです。
- N: 煙を流した実験では、上を通る空気のほうが、ずっと先に後ろへ着きました。
- B（吹き出し）: うえが さきだ！
- N: 紙飛行機の平らなつばさも、上と下が同じ形なのに、ちゃんと飛びます。

## 8. 正解とみてみよう
- N: 正解は2番。つばさが空気を下へ曲げて、その反動で持ち上げられていたんだね。
- N: 紙飛行機を作ったら、つばさを横から見てみよう。
- N: 空港の展望デッキでは、車輪がどこで地面からはなれるか、見てみよう。
- N: 紙飛行機は、人の顔に向けて飛ばさないでね。
- N: 空港では、決められた場所から見よう。

## 9. おわり
- S（吹き出し）: またね！
- B（吹き出し）: またねー！
