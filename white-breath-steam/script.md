# ゆげと しろい いき 台本（案）

タイトル：寒いとき、湯気や白い息が見えるのはなぜ？｜みのまわり図鑑 ゆげと しろい いき

出どころ：everyday-trivia `trivia/steam-white-breath.md`（メモ：`ideas/notes/white-breath-steam.md`）
cast.py：正解は3番、吹き出しは B → S → K

## 1. つかみ（寒い朝の白い息、やかんの湯気）
- N: 寒い朝、外で「はー」と息をはくと、白いもやが出てきます。
- B（吹き出し）: はー！ しろい！
- N: やかんでお湯をわかしたときの湯気も、白く見えますね。
- N: 寒いとき、湯気や白い息が白く見えるのは、どうしてでしょう。

## 2. 予想
- N: 白いものの正体は、何だと思う？ 予想してみよう。
- N: 1番。けむり。
- N: 2番。水が気体になった、水蒸気。
- N: 3番。とても小さな、水のつぶ。
- N: まずは、やかんの湯気をよく見てみましょう。

## 3. 白いものの正体（水蒸気は見えない。白いのは小さな水のつぶ）
- N: お湯がわくと、水は「水蒸気」という気体になります。
- N: でも、水蒸気は、目に見えません。
- N: 白く見えているのは、水蒸気が冷えてできた、とても小さな水のつぶ。
- N: たくさんのつぶが、光をあちこちへちらすので、白く見えるんです。

## 4. やかんの口のすぐ上は、とうめい
- N: やかんの口のすぐ上をよく見ると、白くなる前に、とうめいなすきまがあります。
- N: そこにあるのは、まだ冷えていない水蒸気。
- N: 少しはなれて冷えたところで、水のつぶになって、白く見えるんです。
- S（吹き出し）: すぐ うえは とうめい！

## 5. 空気がもてる水蒸気の量は、温度で決まる（雲も同じ）
- N: では、どうして冷えると、つぶになるんでしょう。
- N: 空気がもてる水蒸気の量は、温度で決まっています。
- N: あたたかい空気はたくさんもてて、冷たい空気は少ししかもてません。
- N: だから、冷やされると、もちきれなくなった水蒸気が、水のつぶになるんです。
- N: 空にうかぶ雲も、同じしくみでできた、水や氷のつぶです。
- K（吹き出し）: くもと おなじ〜

## 6. 白い息（あたたかい息 ＋ 冷たい空気）
- N: では、白い息はどうでしょう。
- N: はく息は、あたたかくて、水蒸気をたくさんふくんでいます。
- N: 外の冷たい空気とまざると、水蒸気をもちきれなくなって、
- N: 小さな水のつぶができます。これが、白い息です。
- N: お湯の湯気も、夏の暑い昼より、冬の寒い朝のほうが、たくさん見えます。

## 7. すぐ消えるわけ
- N: 白い息は、すぐに消えてしまいますね。
- N: まわりのかわいた空気とまざると、水のつぶが、また見えない水蒸気にもどるからです。

## 8. 正解とみてみよう
- N: 正解は3番。白いのは、水蒸気が冷えてできた、とても小さな水のつぶだったんだね。
- N: 寒い朝、外と部屋の中で「はー」と息をはいて、
- N: どちらで白くなるか、予想してからくらべてみよう。
- N: 大人がお湯をわかしたら、はなれたところから、やかんの口のすぐ上を見てみよう。
- N: 湯気の出口は、とても熱いです。手や顔を近づけたり、さわったりしないでね。
- N: お湯をわかすのも、ふたを開けるのも、大人がします。

## 9. おわり
- S: またね！ / B: またねー！

## 言い方のメモ（元記事とメモから）
- 「湯気は水蒸気」と言わない。水蒸気は目に見えない、白いのは小さな水のつぶ、とはっきり言う。
- 「口のすぐ上の透明なすきま」は、やかんの話だけ。白い息の絵では、口の前にすきまを描かない（ルーペの丸で「息＋外の空気→まざると」を見せる）。
- 「何度より寒いと白くなる」とは言わない。息の温度やしめり気の数字も言わない。
- グラフの数字（4.85・9.4・17.3・30.4グラム）は画面だけ。ナレーションでは言わない。
- 絵の約束：水蒸気（見えない）＝みずいろの輪、水のつぶ＝あおい丸。画面に「えでは、わで かいています」と入れる。
