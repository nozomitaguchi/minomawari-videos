言い方の注意：黄色は「秋につくる」と言わない（もともとあった色）。赤は「かくれていた」と言わない（新しくつくる色）。14倍あまりは「ハウチワカエデという木を調べると」と言い、画面にも「しらべた き：ハウチワカエデ」と出す。内側が緑なのは「〜のことがあります」。糖から赤ができる話は「と考えられています」。赤くするわけは「まだわかっていない」で、2つの考えのどちらも正解にしない。「離層で糖がとじこめられる」「晴れの日・寒暖差できれいになる」「茶色い紅葉」は入れない。色素の名前（クロロフィル・カロテノイド・アントシアニン）は画面の小さな文字だけ。


## 1. つかみ（hook）
- N: 秋の公園。モミジは真っ赤に、イチョウは黄色になります。
- S（吹き出し）: いろが ちがうね
- N: ふだんは、どちらも、緑の葉っぱなのに。
- N: 葉っぱは、どうして秋になると、赤や黄色になるんでしょう。

## 2. 予想（guess）
- N: イチョウの葉っぱの黄色は、どこから来たと思う？
- N: 1番。秋に、木が黄色い色を、新しく作った。
- N: 2番。はじめから葉っぱの中にあって、緑にかくれていた。
- N: 3番。お日さまに焼けて、黄色くなった。
- N: 答えをさがしに、葉っぱの中を、大きくして見てみましょう。

## 3. 葉っぱの中：緑の色と黄色の色（inside）
- N: 葉っぱの中には、緑の色と、黄色の色が、入っています。
- N: ふだんは、緑のほうが多いので、葉っぱは緑に見えます。
- N: この緑は、お日さまの光で、木の栄養を作る、大事な色です。

## 4. 黄色は、かくれていた色（yellow）
- N: 秋になると、緑の色がこわれて、だんだんへっていきます。
- N: すると、イチョウの葉っぱでは、かくれていた黄色が、見えてきます。
- N: 黄色は、秋に新しくぬった色ではなく、もともと葉っぱの中にあった色なんです。
- K（吹き出し）: かくれてたんだ〜

## 5. 赤は、秋に新しく作る色（red）
- N: では、モミジの赤は、どうでしょう。
- N: モミジは、寒くなって緑がへるのといっしょに、赤い色を、新しく作ります。
- N: 黄色は、かくれていた色。赤は、秋に新しく作る色。
- N: 葉っぱのちがいは、赤い色を作るかどうか、なんです。

## 6. 日の当たる外側だけ赤い（sun）
- N: 赤くなったモミジの木を、下から見上げてみましょう。
- N: 日の当たる外側は赤いのに、葉っぱが重なった内側は、緑のままのことがあります。
- B（吹き出し）: そとだけ あかい！
- N: ハウチワカエデという木を調べると、外側に当たる日の光は、内側の14倍あまりでした。
- N: 日の当たる葉っぱは、秋になっても、光で、糖という栄養を作りつづけます。
- N: その糖を使って、赤い色がどんどんできる、と考えられています。

## 7. どうして赤くするのかは、まだわかっていない（why）
- N: では、どうしてわざわざ、赤い色を作るのでしょう。
- N: じつは、これは、まだわかっていません。
- N: ひとつは、日がさのように、強い光から葉っぱを守る、という考え。
- N: もうひとつは、虫に「来ても、いいことはないよ」と伝える、という考えです。
- N: いまも、研究する人たちが、調べているところです。

## 8. 正解とみてみよう（look）
- N: 正解は2番。黄色は、はじめから葉っぱの中にあって、緑にかくれていたんだね。
- N: 赤くなったモミジの木の下に立って、そっと見上げてみよう。
- N: 外側と内側、どっちが赤いかな。予想してから、くらべてみよう。
- N: 赤いモミジと、黄色いイチョウの葉っぱを、1枚ずつならべてみよう。
- N: 拾った葉っぱは、口に入れないでね。木に登ったり、枝を折ったりも、しないでね。
