# にじ 台本（案）

タイトル：にじは、どうして雨のあとに出るの？｜みのまわり図鑑 にじ

出どころ：everyday-trivia `trivia/rainbow-after-rain.md`（メモ：`ideas/notes/rainbow.md`）
cast.py：正解は2番、吹き出しは S → B → K

## 1. つかみ（夕立のあと、うしろにお日さま、前の空ににじ）
- N: 夕立がやんで、うしろからお日さまが出てきました。
- N: すると、前の空に、大きなにじ。
- S（吹き出し）: にじだ！
- N: でも、雨がふっているあいだや、すっかり晴れた空には、なかなか出ません。
- N: にじは、どうして雨のあとに出るんでしょう。

## 2. 予想
- N: にじが見つかりやすいのは、いつだと思う？ 予想してみよう。
- N: 1番。雨がいちばん強くふっているとき。
- N: 2番。雨雲が通りすぎて、すぐにお日さまが出たとき。
- N: 3番。雨がやんで何時間もたった、よく晴れたとき。
- N: まずは、にじが出る場所から見てみましょう。

## 3. にじが出る場所（いつもお日さまの反対がわ）
- N: にじは、空のどこにでも出るわけではありません。
- N: 出るのは、いつも、お日さまの反対がわ。
- N: お日さまを背中にして立つと、前の空の雨つぶに、にじが見えます。
- B（吹き出し）: おひさま うしろ！

## 4. 雨つぶの中（入って曲がる → うしろではね返る → 出てまた曲がる）
- N: 空の雨つぶは、しずくの形ではなく、ほとんどまん丸です。
- N: お日さまの光は、雨つぶに入るときに、くっと曲がります。
- N: うしろがわで、鏡のようにはね返って、
- N: 出るときに、もういちど曲がります。

## 5. 色に分かれるわけ（色ごとに曲がり方がちがう）
- N: お日さまの白い光には、いろいろな色の光がまざっています。
- N: 色によって、曲がる角度が少しずつちがうので、白い光が色に分かれます。
- N: 青やむらさきは、赤より少しだけ大きく曲がります。
- K（吹き出し）: いろが わかれた〜

## 6. ひとつの雨つぶから、ひとつの色（外がわが赤、内がわがむらさき）
- N: ひとつの雨つぶから目にとどくのは、ひとつの色だけ。
- N: 赤は高いところの雨つぶから、むらさきは低いところの雨つぶからとどきます。
- N: だから、にじの外がわは赤、内がわはむらさきになるんです。

## 7. ほんとうは丸い輪（お日さまが低いほど大きく、夏のお昼は見えない）
- N: にじは、ほんとうは丸い輪で、下のほうは地面にかくれて見えません。
- N: お日さまが低いほど、地面の上に出るにじは大きくなります。
- N: お日さまが高すぎる夏のお昼には、にじは地面の下に入って、見えません。

## 8. だから雨のあと（3つがそろうとき）
- N: にじができるには、3つがそろわないといけません。
- N: お日さまがうしろにあること、前に雨つぶがあること、その雨つぶに光が当たっていること。
- N: 雨がふっているあいだは、お日さまが雲にかくれていることが多く、
- N: 雨がすっかりやむと、空の雨つぶがなくなります。
- N: だから、雨雲が通りすぎて、すぐにお日さまが出たときが、ねらいめなんです。

## 9. 正解とみてみよう
- N: 正解は2番。雨雲が通りすぎて、すぐにお日さまが出たときだったね。
- N: よく晴れた日に、大人といっしょに、お日さまを背中にして立ってみよう。
- N: ホースやきりふきで、前に細かい水しぶきを出すと、頭のかげのまわりに、にじができるよ。
- N: お日さまは、ぜったいに直接見ないでね。
- N: 水は、人や電気のものに向けないでね。

## 10. おわり
- S: またね！ / B: またねー！
