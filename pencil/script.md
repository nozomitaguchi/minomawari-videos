## 1. つかみ（hook）
- N: えんぴつで書いた字を、消しゴムで、ごしごし。
- S（吹き出し）: きえた！
- N: 黒い線が、きれいに、なくなりました。
- N: えんぴつの字は、どうして、消しゴムで消えるんでしょう。

## 2. 予想（guess）
- N: えんぴつの字が、消しゴムで消えるのは、どうしてだと思う？
- N: 1番。消しゴムが、黒い色を、白くぬりつぶすから。
- N: 2番。消しゴムが、紙を、うすくけずりとるから。
- N: 3番。黒いつぶが、紙から、消しゴムに、くっつくから。
- N: 答えをさがしに、まず、えんぴつで書くところを、大きくして見てみましょう。

## 3. 書けるしくみ（write）
- N: えんぴつの芯は、黒鉛という黒いこなと、ねん土を、焼いてかためたものです。
- N: まわりの木は、芯を守って、手を黒くしないためのもの。
- N: 紙に書くと、芯が、少しずつ、くだけます。
- N: くだけた黒鉛のつぶが、紙のせんいにくっついて、線になるんです。
- B（吹き出し）: くろい つぶつぶ！

## 4. 消えるしくみ（erase）
- N: では、消しゴムでこすると、どうなるでしょう。
- N: 黒鉛のつぶは、紙よりも、消しゴムのほうに、くっつきやすいんです。
- N: こすると、つぶは、まず、消しゴムの表面に、くっつきます。
- N: つぎに、消しかすに、つつみこまれます。
- N: こうして、黒いつぶは、紙からも、消しゴムからも、とりのぞかれるんです。
- N: 消しかすが出ると、黒くなった面がはがれて、まだ黒くない面が出てきます。

## 5. 色えんぴつは消えにくい（color）
- N: じゃあ、色えんぴつは、どうでしょう。
- N: ろうの入った色えんぴつは、消しゴムでは、消えにくいんです。
- N: ろうがとけて、紙の中まで、入ってしまうこと。
- N: そして、ろうが、消しゴムに、なじみにくいことが、理由です。

## 6. 昔はパンで消した（bread）
- N: 消しゴムがなかったころは、なんと、パンで、えんぴつの線を消していました。
- K（吹き出し）: パンで！？
- N: 1770年、イギリスの化学者プリーストリーが、「えんぴつのあとを消すのに、とても向いたものを見た」と、本に書きました。
- N: それが、天然のゴムです。

## 7. 正解とみてみよう（look）
- N: 正解は3番。黒いつぶが、紙から、消しゴムに、くっつくからだったんだね。
- N: ノートの字を、消しゴムで消したら、消しかすを見てみよう。
- N: 白い消しゴムなのに、消しかすは、灰色っぽくなっているよ。
- N: 紙の上の黒いつぶを、つつみこんで、とったからだね。
- N: 消す前の字と、消したあとの紙も、くらべてみよう。
- N: えんぴつの線と、色えんぴつの線を、消しくらべるのも、おもしろいよ。

## 8. おわり（end）
- S（吹き出し）: またね！
- B（吹き出し）: またねー！
