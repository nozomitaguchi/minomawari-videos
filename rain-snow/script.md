# 雨と雪 台本

出どころ：everyday-trivia `trivia/rain-snow.md`（同じような灰色の雲でも雨の日と雪の日・雲の粒は半径0.001〜0.01ミリで落ちる速さは1秒に約1センチ・上にのぼる風・ぶつかって合体して大きく重くなると落ちる・0.02ミリ→2ミリで長さ100倍、体積100万倍・空は上ほど気温が低い・マイナス5℃を下回るとちりが芯になって少しずつ氷の粒・水蒸気を取りこんで雪の結晶・日本付近で降る雨のほとんどは氷の粒や雪がとけたもの・0℃以上の空気に入るととけはじめる・とけきらないと「みぞれ」・地面の近くに冷たい空気の層があると雪のまま届きやすい・空気がかわいていると0℃以上でも雪のまま届くことがある（蒸発で熱がうばわれる、プールから上がるとひんやり）・みてみよう）／メモ `ideas/notes/rain-snow.md`
正解：1番（cast.py）／吹き出し：B → S → K（おわり S・B）
言い方の注意：「日本でふる雨のほとんど」と言い、「すべての雨が雪から」とは言わない（暖かい雨もある）。雨か雪かの気温の境目を1つの数字で言わない。湿度は「かわいていると、少しあたたかくても雪のままとどくことがある」まで。雨・雪・みぞれの落ちる速さのちがいは答えを言わず「くらべてみよう」。ひょう・あられは入れない（時間の都合）。


## 1. つかみ（hook）
- N: 灰色の雲から、雨がふる日があります。
- N: 同じような灰色の雲なのに、雪がふる日もあります。
- B（吹き出し）: ゆきが いい！
- N: 雨と雪は、空のどこで分かれるんでしょう。

## 2. 予想（guess）
- N: 日本でふる雨は、空の高いところでは、どんなすがただと思う？
- N: 1番。氷のつぶや、雪。
- N: 2番。はじめから、水のつぶ。
- N: 3番。わたのような、ふわふわのかたまり。
- N: 答えをさがしに、雲の中をのぞいてみましょう。

## 3. 雲のつぶは小さすぎて落ちてこない（cloud）
- N: 雲は、とても小さな、水や氷のつぶの集まりです。
- N: つぶが小さすぎて、落ちる速さは、1秒に1センチくらい。
- N: 雲の中には、上にのぼる風もあるので、なかなか落ちてきません。
- S（吹き出し）: おちないんだ！

## 4. くっついて大きくなると落ちる（grow）
- N: つぶどうしがぶつかって、くっつくと、だんだん大きく、重くなります。
- N: 雲のつぶが雨つぶになるには、長さで100倍、かさでは100万倍に、育たなければなりません。
- N: そうして、やっと、地面まで落ちてきます。

## 5. 空の上は寒い。氷のつぶから雪へ（ice）
- N: 空は、高いところほど寒くなります。
- N: マイナス5度より寒い雲の中では、小さなちりを芯にして、少しずつ氷のつぶができます。
- N: 氷のつぶは、目に見えない水蒸気を取りこんで育ち、雪の結晶になります。
- N: 日本でふる雨のほとんどは、空の上では、この氷のつぶや雪なんです。
- K（吹き出し）: びっくり！

## 6. とけるかどうかは、落ちる道しだい（path）
- N: では、どこで雨と雪に分かれるのでしょう。
- N: 空気は、地面に近づくほど、あたたかくなります。
- N: 落ちてくる雪は、0度よりあたたかい空気に入ると、とけはじめます。
- N: すっかりとけて、地面に着くと、雨。
- N: 地面の近くに、冷たい空気の層があると、雪はとけないまま、とどきやすくなります。
- N: とけきらないうちに着くと、雨と雪がまじった「みぞれ」です。

## 7. 地上の気温だけでは決まらない（dry）
- N: でも、地面の近くの気温だけでは、決まりません。
- N: 空気がかわいていると、少しあたたかくても、雪のままとどくことがあります。
- N: 雪から水が蒸発するときに、熱がうばわれて、雪がなかなかとけないからです。
- N: プールから上がると、体がひんやりするのと、同じです。

## 8. 正解とみてみよう（look）
- N: 正解は1番。日本でふる雨のほとんどは、空の上では、氷のつぶや雪だったんだね。
- N: 雨や雪、みぞれの日に、部屋の中から、窓の外を見てみよう。
- N: どれがいちばん、ゆっくり落ちてくるかな。予想してから、くらべてみよう。
- N: 地面や窓についたあとの形も、見てみてね。
- N: 見るときは、窓の中から。窓から身を乗り出したり、こおった道に出たりしないでね。

## 9. おわり（end）
- S（吹き出し）: またね！
- B（吹き出し）: またねー！
