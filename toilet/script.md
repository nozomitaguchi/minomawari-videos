# トイレ 台本

出どころ：everyday-trivia `trivia/toilet-water.md`（流してもしばらくすると同じくらいの高さまで水がたまっている・タンクには次に流す水・便器の底にも水・奥の排水の道は曲がっていて水がたまる＝トラップ・封水深は5〜10cm・レバー→鎖→ゴムフロート（排水口のふた）が開いてタンクの水が便器へ・サイホン式は排水の道を水でいっぱいにして便器の水ごと引き出す（6〜9歳むけ「ストローで すうように」）・流すと便器の水がほとんどなくなる・浮玉が下がって水が入り、たまると浮玉が上がって止まる・便器にも約1〜2分水を補給して元の位置に戻す・下水のにおいや害虫をふせぐ水のふた・水がなくなるとにおいが部屋に・長く使わないと蒸発してへる・みてみよう）／メモ `ideas/notes/toilet.md`
正解：3番（cast.py）／吹き出し：S → K → B（おわり S・B）
言い方の注意：「すぐあとは水がほとんどない」「1〜2分かけて足す」はサイホン式の便器の話なので「便器によっては」と言い、画面にも「サイホンしきの べんき」と出す。便器へ足す水が通る管の名前は出さない（タンクのほうから足す絵にとどめる）。洗い落とし式の水面の動きは言わない。数字は封水深の5〜10センチと、1〜2分だけ。「おつり」（水はね）は入れない（時間の都合）。


## 1. つかみ（hook）
- N: トイレを流すと、水はジャーッと、いきおいよく流れていきます。
- S（吹き出し）: ぜんぶ ながれた？
- N: でも、しばらくすると、便器の底には、また水がたまっています。
- N: トイレは、流したあとも、どうして水が残るんでしょう。

## 2. 予想（guess）
- N: 流したあと、便器に水が残るのは、どうしてだと思う？
- N: 1番。流す水が、あまってしまうから。
- N: 2番。便器を、冷やすため。
- N: 3番。くさいにおいが、上がってこないようにするため。
- N: 答えをさがしに、トイレを横から切って、中を見てみましょう。

## 3. 便器の中：曲がった道に水がたまる（trap）
- N: 流す前。タンクには、次に流す水がためてあります。
- N: 便器の底にも、水があります。
- N: 便器のおくの、水が出ていく道は、くねっと曲がっていて、そこに水がたまるのです。
- N: この曲がった道を、「トラップ」といいます。たまる水の深さは、5センチから10センチ。
- K（吹き出し）: くねくねだ〜

## 4. 流すと、水はどう進む？（flush）
- N: レバーを回すと、鎖が、タンクの底のふたを引っぱって開けます。
- N: タンクにためた水が、便器へ、いきおいよく流れ出します。
- N: 便器によっては、曲がった道が、水でいっぱいになります。
- N: すると、ストローで吸うように、便器の水ごと、引っぱり出します。
- N: だから、流したすぐあとは、水がほとんどなくなります。
- B（吹き出し）: みず ないよ！

## 5. 流したあと、水はどう戻る？（refill）
- N: そのあとタンクでは、水にうかんだ浮き玉が下がって、水が入りはじめます。
- N: 水がたまると、浮き玉が上がって、水が止まります。
- N: 便器にも、1分から2分かけて水を足して、もとの高さにもどします。

## 6. 残る水の役目（role）
- N: どうして、わざわざ水をもどすのでしょう。
- N: トイレの先は、下水の管につながっています。
- N: 曲がった道の水が、ふたになって、下水のくさいにおいや虫を、止めているんです。
- N: もし水がなくなると、いやなにおいが、部屋まで上がってきてしまいます。
- N: 長く使わないと、この水が蒸発して、へってしまうこともあります。

## 7. 正解とみてみよう（look）
- N: 正解は3番。くさいにおいが、上がってこないようにするためだったんだね。
- N: おうちのトイレで、流す前に、水の広さを見ておこう。
- N: 流したすぐあとと、1、2分あとでは、どうちがうかな。予想してから、くらべてみよう。
- N: タンクの「シャー」という音が、いつ止まるか、時計を見ながら聞いてみよう。
- N: 流すのは、大人といっしょに。便器の中に手を入れたり、タンクのふたを開けたりしないでね。

## 8. おわり（end）
- S（吹き出し）: またね！
- B（吹き出し）: またねー！
