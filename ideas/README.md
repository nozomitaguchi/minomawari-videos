# 動画ネタ帳

「みのまわり図鑑」の既存記事から探すだけでは拾えない、動画のための問いを集める。身近な場面で始まり、動き・音・くらべる映像のどれかで答えが伝わるものを置く。

「状態」は、**候補**、**採用**、**下調べ中**、**制作一覧へ追加**、**見送り**。動画化するものは、使う資料や検証結果をメモして [制作一覧](../VIDEOS.md) に追加する。元記事がまだない題材もここで検討できる。

## 身の回りのものを深掘りする

毎日見たり使ったりするものから出発し、中の仕組みや、見た目の違いが生まれる理由をたどる。一つ目の答えから次の疑問が自然につながる題材を優先する。

### ユーザーが挙げた4テーマ

| タイトル案 | 掘り下げる順番 | 冒頭で見せるもの | 状態 |
|---|---|---|---|
| 空の上では何が起きて、雨になったり雪になったりするの？ | 雲の中で粒が育つ → 落ちはじめる → 地面までの空気の温度によって、途中でとけるかが変わる。 [気象庁「雨が降る仕組み」](https://www.data.jma.go.jp/sendai/knowledge/kyouiku/yoho/ame.pdf) | 同じ雪の粒を、暖かい空気の層を通る道と、冷たいままの道に分けて追いかける。 | 候補 |
| おふとんは、どうして入ったときは冷たいのに、だんだんあったかくなるの？ | 熱はどこから来る？ → 中わたにある空気は何をしている？ → ふかふかと、ぺちゃんこではどう違う？ [図鑑「ふとんはなぜあたたかいのか」](https://github.com/nozomitaguchi/everyday-trivia/blob/main/trivia/futon-warmth.md) | 同じ暖かさの容器を、何もかけない場合・ふかふかな布・同じ布を押しつぶした場合で比べる。 | 候補 |
| 冬、葉っぱがなくなる木と、緑のままの木があるのはなぜ？ | 落葉樹と常緑樹を同じ公園で見比べる → 葉を残すと何が得で、何が大変？ → 緑のままの木も葉っぱが入れ替わる。 [東京大学「農学なぜなぜ？」](https://www.iai.ga.a.u-tokyo.ac.jp/mizo/dream%2B21c/dream/public_html/tabemono/answer1.html) | 冬の公園のイチョウとツバキを並べ、同じ場所の木が別々の冬の過ごし方をするところから入る。 | 候補 |
| 鍵を回すと、ドアの中で何が動いて開くの？ | 鍵の形が合うとはどういうこと？ → 何がそろうと回せる？ → 回した動きがどうやってドアのかんぬきに届く？ [精密工学会誌の解説](https://www.jstage.jst.go.jp/article/jjspe/73/1/73_1_72/_pdf/-char/ja) | 合う鍵と合わない鍵を、ピン式の錠の断面アニメで見比べる。最後にドア側面のかんぬきまで追う。 | 候補 |
