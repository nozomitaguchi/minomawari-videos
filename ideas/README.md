# 動画ネタ帳

「みのまわり図鑑」の既存記事から探すだけでは拾えない、動画のための問いを集める。身近な場面で始まり、動き・音・くらべる映像のどれかで答えが伝わるものを置く。

「状態」は **候補 → 下調べ中 → 制作一覧へ追加**。動画化するものは、使う資料や検証結果をメモして [制作一覧](../VIDEOS.md) に追加する。元記事がまだない題材もここで検討できる。
