## 問い

走ると、どうして心臓がドキドキするの？
答えの軸：**走っている足の筋肉は、酸素（さんそ）を使って力のもとを作り、それで縮んでいる。酸素を運ぶのは血で、血を送るのは心臓というポンプ。走ると心臓は、1分に打つ回数をふやし（休みの約75回 → 150回くらいまで）、1回に送り出す血の量もふやす（約70ミリリットル → 約130ミリリットル）。送る血は休みの4〜5倍になり、ふえた分のほとんどは走っている筋肉へ行く。心臓を速くするのはアクセル役の神経、おそくするのはブレーキ役の神経で、自分で「速くなれ」と思って速くするのではない。止まると最初の1分ほどで速く、そのあとゆっくりもどる。**

## 見せ場

- 予想の3択の例：「はしると しんぞうは、なにを ふやして いる？」（うつ かいすう だけ／1かいに おくる ちの りょう だけ／りょうほう → 正解は りょうほう）。または「ふえた ちは、どこへ いく？」（あたま／はしって いる あしの きんにく／おなか → 正解は あしの きんにく）。正解の番号は cast.py に従う
- 心臓は「回数」×「1回の量」：コップの大きさと回数がどちらもふえて、送る血が4〜5倍に（`hb-two-ways`）。数字は「4〜5ばい」だけでもよい
- ふえた血は、走っている筋肉への太い道へ。おなかや腎臓への道はほそくなる（`hb-to-muscle`）
- 血のしずくの中の酸素のつぶ10こ：休みは2〜4こ、激しい運動では7〜8こを筋肉が受け取る（`hb-extract`）
- アクセルとブレーキ：何もしないと1分に約100回のリズム → ふだんはブレーキで約75回 → 走るとブレーキをゆるめてアクセル（`hb-accel-brake`、`hb-pacemaker`）
- 「ドックン」の音は、心臓の中のとびら（弁）がパタンと閉じる音（`hb-sound`）。つかみや最初の場面に使える
- 止まると最初の1分でぐっと下がるグラフ（`hb-recovery`）。子どもの心臓は大人より速く打っている（`hb-age`）

## 場面の順番（説明は5場面）

1. 心臓は血を送るポンプ。体からもどった血を肺へ、肺で酸素をもらった血を体じゅうへ。「ドックン」は弁が閉じる音（`hb-pump`、`hb-sound`）
2. 走る足の筋肉は、酸素を使って力のもとを作る。酸素がたくさんいるほど心拍数は上がる（`hb-muscle-oxygen`、`hb-need-more`）
3. 心臓は「打つ回数」と「1回の量」を両方ふやし、送る血は4〜5倍（`hb-two-ways`、`hb-output`）
4. ふえた血はおもに走っている筋肉へ。筋肉は血から酸素を多く受け取る（`hb-to-muscle`、`hb-extract`）
5. だれが速くする？ アクセルとブレーキの神経。脳は走り出す前から準備を始める。止まると最初の1分で速くもどる（`hb-accel-brake`、`hb-pacemaker`、`hb-signals`、`hb-recovery`）

みてみよう：走る前に胸に手を当てて、大人が10秒はかるあいだの「ドックン」を数える。広い公園で少し走ったあと、もう一度数えてくらべる。1分休むとどのくらいもどるかも予想してから確かめる（`hb-look`、`hb-pulse`）。

## 注意書き・言いかたの注意

- **走るのは広くて車の来ない場所で。苦しい・気持ちが悪い・胸が痛いときは、すぐ止まって大人に言う。むりに速く・長く走らない。** 動画の「みてみよう」で必ず言う。子ども向けには病気の話はしない（記事の大人向けにだけ「お医者さんから運動の決まりを言われている子はそれを守る」）
- 「はしる まえから ドキドキ する」とは言わない。資料は「脳の調節の場所は、運動が始まる前から働いている」まで（inbox）。「のうが じゅんびを はじめて いる」と言う
- 休みにもどるまで何分、とは言わない（資料は「最初の1分は速く、そのあとゆっくり」まで）
- 75回・150回・70ミリリットル・130ミリリットル・4〜5倍は、OpenStax の「体重70kgの人」「健康な若い人」の例。子どもの数字ではない。言うなら「おとなの れい」と添えるか、「4〜5ばい」だけにする
- 子どもの休みの心拍数は「おとなより はやい（100を こえる ことも おおい）」まで。子どもが速い理由は資料になく、言わない
- 筋肉へ行く血の割合（％）は確かめていない（inbox）。「ほとんどが はしって いる きんにくへ」と言う
- 心臓の大きさ（にぎりこぶし）・重さ・1日に何回、は確かめていない。言わない
- 吹き出しの例：おとうと「ドキドキ してる！」（つかみ、走ったあと胸に手）／おねえちゃん「さっきより はやい！」（みてみよう）／カメレオン（ルーペで弁の「パタン」をのぞく）
