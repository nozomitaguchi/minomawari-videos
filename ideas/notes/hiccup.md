# hiccup（しゃっくり）動画用メモ

サイト：https://nozomitaguchi.github.io/everyday-trivia/i/hiccup/
図：`everyday-trivia/assets/figures-hiccup.js`（名前はすべて `hc-` ではじまる。いちばん上の絵は `hiccup-diaphragm`）
色の約束：すう息＝あお、はく息＝オレンジ、横隔膜＝ちゃいろ（ピクッとするときは あか）、声のとびら（声門）＝あか、神経＝きいろ、延髄（脳の奥）＝むらさき

## 問い

しゃっくりは、どうして急に出て止まらないの？
答えの軸：**しゃっくりは、息を吸うときに使う胸の下の筋肉「おうかくまく（横隔膜）」が、自分で動かそうとしなくても勝手にピクッと縮むことから始まる。空気がヒュッと吸いこまれたところで、のどの奥の声のとびら（声門）が約0.035秒でパタンと閉じる。「ヒック」はそのとびらが閉じて空気がせき止められる音なので、息を吸うときに鳴る。命令は脳の奥の呼吸の場所（延髄の呼吸中枢）から来ると考えられていて、一度始まると何回もくり返すが、たいていは数分で止まる。何のためにあるのかは、まだわかっていない。**

## 見せ場

- 予想の3択の例：「『ヒック』の おとは、どこで なって いる？」（おなか／のどの おくの とびら／はなの なか → 正解は のどの おくの とびら）。または「『ヒック』は いきを すう とき？ はく とき？ とめた とき？」（→ すう とき）。正解の番号は cast.py に従う
- からだの横の断面で、横隔膜（ちゃいろの線）が急に赤くなって「ピクッ」と下がる → 青い矢印がヒュッと鼻から入る → のどの赤いとびらがパタンと閉じて「ヒック！」（`hiccup-diaphragm`、`hc-spasm`、`hc-sound`）
- 声門を上から見た絵で、開いた三角のすき間が「あっという間」にぴったり閉じる。時間の線に「0.035びょう」（`hc-glottis`）。スローモーションにすると映える
- ふだんの「すう・はく」との比べ：ふつうはゆっくり下がる横隔膜が、しゃっくりでは勝手にピクッ（`hc-breath` → `hc-spasm`）
- おなかの中の赤ちゃんも妊娠9週ごろからしゃっくりをしている。生まれたばかりの赤ちゃんでは、しゃっくりのたびに脳に大きな波が3つ出る（UCL、2019年。`hc-fetus`、`hc-newborn`）
- 何のため？ → まだわかっていない。オタマジャクシは水を吸ってえらに送るとき、肺に水が入らないよう声門を閉じる。「吸う＋とびらを閉める」が同じ、という考え（仮説）がある（`hc-tadpole`）

## 場面の順番（説明は5場面）

1. 息を吸う筋肉「おうかくまく」：胸とおなかのさかいのドームのような筋肉。縮んで下がると肺に空気が入る。ふだんの息は考えなくても、ねていても続く（`hc-breath`、`hc-brain`）
2. しゃっくりの始まり：おうかくまくが勝手にピクッと縮んで、空気が急に吸いこまれる（`hc-spasm`）。命令は脳の奥の呼吸の場所（延髄）から（`hc-center`）
3. 声のとびらがパタン：吸いはじめて約0.035秒で声門が閉じる → 空気がせき止められて「ヒック」。だから吸うときに鳴る（`hc-glottis`、`hc-sound`）
4. どうして止まらない？ 一度始まると何回もくり返すが、たいていは数分で止まる（`hc-minutes`）。きっかけは炭酸・食べすぎ・急な暑さ寒さ・わくわく・空気を飲みこむ、など（`hc-triggers`）。息を止めても続くことがあり、「止める方法」の効きめははっきりしない（`hc-hold`、`hc-remedies`）
5. おなかの赤ちゃんもしゃっくりをする。何のためかは まだわかっていない（オタマジャクシの仮説）（`hc-fetus`、`hc-newborn`、`hc-tadpole`）

みてみよう：自分や家族がしゃっくりをしたら、「ヒック」が鳴るのは息を吸うときか、はくときか、耳をすませて確かめる（答えは吸うとき。`hc-look`）。

## 注意書き・言いかたの注意

- **止めようとして水を一気に飲んだり、食べものをたくさん飲みこんだりしない。袋（とくにビニール袋）を口や鼻にかぶせない。人をおどかして止めようとしない。** 動画の「みてみよう」で必ず言う
- 2〜3日以上続くときは、おうちの人に話してお医者さんへ（MSDマニュアル家庭版）。子ども向けには「2にち つづいたら おいしゃさんに」程度で、こわがらせない。病気の話（脳や胃の病気など）にはふみこまない
- 「〇〇をすると止まる」とは言わない。言い伝えの方法（息を止める・水・砂糖・紙袋）は「ききめは はっきり しない」（MSD）。びっくりさせる・鼻をつまんで水、は確かめていない（inbox）
- 0.035秒は Straus ほか 2003 の図の説明（息が流れこみはじめてから約35ミリ秒）。「あっという間」と言いかえてもよい
- 1分に何回、最長記録などの数字は記事にない（確かめていない）。言わない
- 何のためにあるかは「まだ わかって いない」と必ず言う。オタマジャクシの話は「そういう かんがえも ある」と弱めに。「しゃっくりは脳を育てる」と言い切らない（「たすけて いるのかも しれない」まで）
- お酒もきっかけになるが、子ども向けの動画では言わなくてよい
- 吹き出しの例：おとうと「ヒック！ ヒック！」（つかみ）／おねえちゃん「すう ときに なってる！」（みてみよう）／カメレオン（ルーペで のどの とびらを のぞく）
