# みのまわり図鑑｜動画のもとになる記事を作る指示書

## 依頼

`nozomitaguchi/everyday-trivia` に、**鍵・冬の木・雨と雪・トイレ・車の仕組み・車輪から自動車までの歴史**の元記事を作ってください。車の2テーマは既存記事を調べ、必要に応じて追記または新記事で補ってください。`WRITING.md` と `README.md` を先に読み、既存記事の粒度、年齢別の文章、図解、出典の書き方に合わせてください。

入口は、子どもが自分で見たり使ったりした場面にします。そこから「中では何が動く？」「なぜそうなる？」「条件が変わるとどう違う？」の順に、次の疑問がつながるようにしてください。**1テーマにつき、動画の中心にする1問を1記事**。

サイトはしばらく育てず、トークンは動画づくりに使う方針です。今回の記事は、動画の元にするための例外として作ります。「済」の条件を満たすための周辺記事は、ユーザーから頼まれたときだけ増やします（新しい「もの」が「済」になっていなくてもかまいません）。

このセッションは `everyday-trivia`（記事）と `minomawari-videos`（`VIDEOS.md` と動画用メモ）の両方に push します。

## 動画ごとの元記事

### 1. 鍵を回すと、ドアの中で何が動いて開くの？

- **入口**　似ている二つの鍵を並べ、合うかどうかで回り方が変わるところから始める。
- **掘り下げる順番**　鍵を差す → 中のどの部品がそろうと回せるか → 回した力がドア側面のかんぬきにどう届くか。ピン式の錠を例にし、例にした方式と一般的な話を区別する。
- **図解**　鍵を差す前・合う鍵を差した状態・回したあとを、同じ断面と向きで並べる。鍵穴からドアの側面へ視点を移し、最後はかんぬきが動くところまでつなぐ。
- **確認する資料**　錠前メーカーの構造図や技術資料、精密工学会の錠前の解説。シリンダーと錠ケースの関係まで確認できる資料を探す。
- **つながり**　既存の[車のキー](https://github.com/nozomitaguchi/everyday-trivia/blob/main/trivia/car-ignition-key.md)と[エレベーターの消防用の鍵穴](https://github.com/nozomitaguchi/everyday-trivia/blob/main/trivia/elevator-fire-service-keyswitch.md)から、互いにリンクする。
- **みてみよう**　大人が開けたドアの側面で、鍵を回すとどの金具が動くか見る。**注意**として、ドアのすき間や金具に指を入れないこと、鍵は大人が回すことを、本文と子ども向けの文の両方に書く。

### 2. 冬、葉っぱがなくなる木と、緑のままの木があるのはなぜ？

- **入口**　同じ冬の公園にあるイチョウとツバキなど、見比べられる身近な2種類から始める。
- **掘り下げる順番**　葉は何をしている？ → 冬には、水や光を使う条件がどう変わる？ → 葉を落とす方法と残す方法にはそれぞれどんな利点や負担がある？ → 緑のままの木は、いつ葉を入れ替える？
- **図解**　同じ場所・同じ季節の2本を並べる。葉と枝の近くに寄り、必要に応じて春までの変化を小さな季節図で見せる。
- **確認する資料**　大学、森林研究機関、植物園の資料。例に出す樹種の葉の寿命や落ちる時期は、樹種ごとの資料でも確かめる。落葉の理由をすべての木で一つに決めつけない。
- **みてみよう**　同じ散歩道で枝だけの木と緑の木を探し、枝先と木の下を見比べる。落ちている実や葉を口に入れないことを書く。

### 3. 空の上では何が起きて、雨になったり雪になったりするの？

- **入口**　地上から同じように雲を見上げても、雨の日と雪の日があるところから始める。
- **掘り下げる順番**　雲の中にある小さな粒 → 粒が成長して落ちはじめる → 落ちる途中で暖かい空気を通る場合と、冷たい空気を通る場合 → 地上の気温だけで雨か雪かが決まらない理由。
- **図解**　雲から地面までを1枚の縦断面で描き、雨になる道と雪のまま届く道を並べる。必要ならみぞれまで示す。雨の成り立ちは、氷の粒がとける場合と、水滴のまま育つ場合を混同しない。
- **気温と湿度**　「地上の気温だけで決まらない」理由には、上空の気温に加えて、湿度（空気のかわき具合）も関わるかを資料で確かめる。確かめられた範囲だけ書き、数字は資料にあるものだけにする。
- **確認する資料**　気象庁の「雨・雪について」「雨が降る仕組み」や降水の解説。既存の雨雲の記事にはリンクし、今回は雲の色よりも粒が地面に届くまでを扱う。
- **みてみよう**　窓から降り方を見て、雨・雪・みぞれで落ち方や地面についたあとがどう違うか比べる。

### 4. トイレは、流したあともどうして少し水が残るの？

- **入口**　一度水が流れていくのに、しばらくすると便器にまた水があるところから始める。
- **掘り下げる順番**　流す前の水はどこにある？ → 流すと便器の奥をどう進む？ → 流したあとの水はどう戻る？ → 残る水にはどんな役目がある？
- **図解**　同じ便器の断面を、流す前・途中・あとで並べる。便器に残る水の高さと、排水の道を色分けする。
- **確認する資料**　衛生陶器メーカーの断面図や技術資料、自治体などの排水設備資料。流し方や水の補い方は、例にする便器の方式を決めて確認する。
- **みてみよう**　いつものトイレで流す前と数秒後の水面を見比べる。流すのは大人といっしょにすること、便器の中に手を入れないことを書く。

### 5. アクセルを踏むと、どうやってタイヤまで力が届くの？

- **入口**　止まった車のアクセルを踏む場面から始める。「ペダルとタイヤは離れているのに、何が間をつないでいる？」を問いにする。
- **掘り下げる順番**　普通のガソリン車を一例にする。ペダルで運転手の指示が伝わる → エンジンの中で生まれたピストンの上下の動きが回転になる → 変速機などを通って回転が車輪まで届く → タイヤと道路の間で押す力が働き、車体が進む。変速機を扱う場合は、同じ自転車でもギアを変えると踏み心地が違う、という身近な経験につなげる。
- **図解**　車の横断面に、ペダルからタイヤまで順に色をつける。エンジンのところだけ拡大して上下運動と回転を対比し、最後にタイヤと地面を横から見せる。EVにも触れるなら、モーターで回すところだけを短く比較する。
- **確認する資料**　[既存のエンジン記事](https://github.com/nozomitaguchi/everyday-trivia/blob/main/trivia/car-engine-basics.md)を土台にし、変速機と駆動輪までの伝わり方をメーカーや自動車工学の教材で確認する。例にした車の方式を明記し、ガソリン車に共通する話と、その方式だけの話を分ける。既存記事の補足で足りるか、動力伝達の独立記事にするかは構成で判断する。
- **みてみよう**　玩具の車や図で、力を受ける車輪はどれか、車輪が床をどちらへ押すかを予想する。本物の車は、エンジンがかかっているときや動いているときに近づかないことを書く。

### 6. 車輪がついた荷車は、いつ自分で走る車になったの？

- **入口**　今の車からエンジンと電池を取り去った絵を見せる。「車輪はある。じゃあ、だれが動かす？」と問いかける。
- **掘り下げる順番**　車輪と車軸を使った荷車で何が変わった？ → 人や馬が引いた時代 → 動力を車に載せた蒸気車 → ガソリン車や初期の電気自動車 → 必要なら今の車まで。各場面の問いを「何が車輪を回したか」でそろえる。船や鉄道などは必要な背景にとどめ、今回は陸の荷車から自動車までを追う。
- **図解**　代表例を同じ横向きで並べ、車輪と、力を出すものを同じ色で追えるようにする。年表には出来事だけでなく「その前の何に困っていたか」を添える。
- **確認する資料**　[既存の自動車史](https://github.com/nozomitaguchi/everyday-trivia/blob/main/trivia/car-history.md)を使い、車輪・車軸の出土品や荷車を描いた資料は[考古学の論文](https://www.cambridge.org/core/journals/antiquity/article/abs/earliest-evidence-of-wheeled-vehicles-in-europe-and-the-near-east/4835B594180234DC116F6F0105771573)や博物館の収蔵資料までたどる。「いま残る初期の証拠」と「発明された場所・年代」を区別する。蒸気車は[フランス工芸博物館の収蔵資料](https://www.arts-et-metiers.net/musee/fardier-vapeur)、ガソリン車は[ベンツの特許出願を記した資料](https://group.mercedes-benz.com/company/tradition/company-history/1885-1886.html)を手がかりにする。「最初の自動車」という表現には、蒸気・ガソリンなど何を指すかを添える。
- **みてみよう**　台車・自転車・車を見比べて、何が車輪を動かすか探す。

## 記事としてそろえるもの

- 既存の形式に合わせた `trivia/*.md` と図解。新しい「もの」や分類が必要な場合は `items/` とサイト側の `README.md` に登録し、目次から辿れるようにする。
- 大人向けの説明、3〜5歳向け、6〜9歳向けの本文、実物を観察する「みてみよう」、参照した出典。数字や条件を入れる場合は、資料のどこで確認できるかを記録する。
- 図は1枚につき一つの変化を見せる。本文の図解と「みてみよう」の絵まで用意する。
- 動画用のメモを `minomawari-videos` の `ideas/notes/<動画ID>.md` に書いて push する。中身は、問い、見せ場、3〜6場面で説明する順番、使える図の名前、注意書き。あとで下書きを作るセッションが読むので、作業報告だけに書いて終わりにしない。
- `node tools/build.mjs` と `python3 tools/check_kids.py` など、既存の確認手順を実行する。図が表示されること、一覧や関連リンクから元記事に辿れることも確認する。

## 制作一覧への渡し方

`nozomitaguchi/minomawari-videos` の `VIDEOS.md` では、**記事を作ってから動画にするもの**を `記事作成待ち` とする。

`記事作成待ち` → `候補` → `下書き中` → 以降は既存の制作手順

`記事作成待ち` の意味と、下書きで拾わない決まりは `CLAUDE.md` にも書いてある。

1. 上の「決めてあるID」の行は、`VIDEOS.md` の「つぎに作る候補」に登録ずみ。並びは `nails-and-hair` のすぐ下、`ant` の上で、**おふとん → 鍵 → 冬の木 → 雨と雪 → トイレ → 車の仕組み → 車輪から自動車までの歴史**の順。
2. 元記事を仕上げ、ビルドと公開リンクを確認できたら、該当行に元記事リンクを付けて `候補` に進める。すべての元記事がそろうのを待たず、記事ごとに進めてよい。`VIDEOS.md` は書きかえる前に `git pull --rebase`、書いたらすぐ push する。
3. 見送り欄の `futon`（干したふとんのにおい）と `car`（「どう走る？」では広い）の行は残す。今回の回は、別の動画ID（`futon-warmth`、`car-drive`、`wheel-to-car`）で扱う。
4. 「雨と雪」の公開順は、「白い雲と雨雲」（`sky-cloud-white`）のあとを目安にする。

作業報告には、元記事の公開URL、検証した出典、動画にするときの見せ場、変えた制作ステータスをテーマごとに書いてください。
