# みのまわり図鑑｜動画のもとになる記事を作る指示書

## 依頼

`nozomitaguchi/everyday-trivia` に、**鍵・冬の木・雨と雪・トイレ**の元記事を作ってください。`WRITING.md` と `README.md` を先に読み、既存記事の粒度、年齢別の文章、図解、出典の書き方に合わせてください。

入口は、子どもが自分で見たり使ったりした場面にします。そこから「中では何が動く？」「なぜそうなる？」「条件が変わるとどう違う？」の順に、次の疑問がつながるようにしてください。最初は **1テーマにつき、動画の中心にする1問を1記事**。各テーマの「済」条件を満たすための周辺記事は、今回の元記事を揃えてから増やせます。

## 4本の元記事

### 1. 鍵を回すと、ドアの中で何が動いて開くの？

- **入口**　似ている二つの鍵を並べ、合うかどうかで回り方が変わるところから始める。
- **掘り下げる順番**　鍵を差す → 中のどの部品がそろうと回せるか → 回した力がドア側面のかんぬきにどう届くか。ピン式の錠を例にし、例にした方式と一般的な話を区別する。
- **図解**　鍵を差す前・合う鍵を差した状態・回したあとを、同じ断面と向きで並べる。鍵穴からドアの側面へ視点を移し、最後はかんぬきが動くところまでつなぐ。
- **確認する資料**　錠前メーカーの構造図や技術資料、精密工学会の錠前の解説。シリンダーと錠ケースの関係まで確認できる資料を探す。
- **みてみよう**　大人が開けたドアの側面で、鍵を回すとどの金具が動くか見る。

### 2. 冬、葉っぱがなくなる木と、緑のままの木があるのはなぜ？

- **入口**　同じ冬の公園にあるイチョウとツバキなど、見比べられる身近な2種類から始める。
- **掘り下げる順番**　葉は何をしている？ → 冬には、水や光を使う条件がどう変わる？ → 葉を落とす方法と残す方法にはそれぞれどんな利点や負担がある？ → 緑のままの木は、いつ葉を入れ替える？
- **図解**　同じ場所・同じ季節の2本を並べる。葉と枝の近くに寄り、必要に応じて春までの変化を小さな季節図で見せる。
- **確認する資料**　大学、森林研究機関、植物園の資料。例に出す樹種の葉の寿命や落ちる時期は、樹種ごとの資料でも確かめる。落葉の理由をすべての木で一つに決めつけない。
- **みてみよう**　同じ散歩道で枝だけの木と緑の木を探し、枝先と木の下を見比べる。

### 3. 空の上では何が起きて、雨になったり雪になったりするの？

- **入口**　地上から同じように雲を見上げても、雨の日と雪の日があるところから始める。
- **掘り下げる順番**　雲の中にある小さな粒 → 粒が成長して落ちはじめる → 落ちる途中で暖かい空気を通る場合と、冷たい空気を通る場合 → 地上の気温だけで雨か雪かが決まらない理由。
- **図解**　雲から地面までを1枚の縦断面で描き、雨になる道と雪のまま届く道を並べる。必要ならみぞれまで示す。雨の成り立ちは、氷の粒がとける場合と、水滴のまま育つ場合を混同しない。
- **確認する資料**　気象庁の「雨・雪について」「雨が降る仕組み」や降水の解説。既存の雨雲の記事にはリンクし、今回は雲の色よりも粒が地面に届くまでを扱う。
- **みてみよう**　窓から降り方を見て、雨・雪・みぞれで落ち方や地面についたあとがどう違うか比べる。

### 4. トイレは、流したあともどうして少し水が残るの？

- **入口**　一度水が流れていくのに、しばらくすると便器にまた水があるところから始める。
- **掘り下げる順番**　流す前の水はどこにある？ → 流すと便器の奥をどう進む？ → 流したあとの水はどう戻る？ → 残る水にはどんな役目がある？
- **図解**　同じ便器の断面を、流す前・途中・あとで並べる。便器に残る水の高さと、排水の道を色分けする。
- **確認する資料**　衛生陶器メーカーの断面図や技術資料、自治体などの排水設備資料。流し方や水の補い方は、例にする便器の方式を決めて確認する。
- **みてみよう**　いつものトイレで流す前と数秒後の水面を見比べる。

## 記事としてそろえるもの

- 既存の形式に合わせた `trivia/*.md` と図解。新しい「もの」や分類が必要な場合は `items/` とサイト側の `README.md` に登録し、目次から辿れるようにする。
- 大人向けの説明、3〜5歳向け、6〜9歳向けの本文、実物を観察する「みてみよう」、参照した出典。数字や条件を入れる場合は、資料のどこで確認できるかを記録する。
- 図は1枚につき一つの変化を見せる。本文の図解と「みてみよう」の絵まで用意する。動画用に切り出すなら、問い・見せ場・3〜6場面で説明する順番も作業報告に残す。
- `node tools/build.mjs` と `python3 tools/check_kids.py` など、既存の確認手順を実行する。図が表示されること、一覧や関連リンクから元記事に辿れることも確認する。

## 制作一覧への渡し方

`nozomitaguchi/minomawari-videos` の `VIDEOS.md` では、**記事を作ってから動画にするもの**を `記事作成待ち` とする。

`記事作成待ち` → `候補` → `下書き中` → 以降は既存の制作手順

1. 合意した新規4テーマは、`記事作成待ち` で制作一覧に置く。この状態は下書きの対象から外し、候補の自動補充でも同じ題材を重ねて登録しない。
2. 元記事を仕上げ、ビルドと公開リンクを確認できたら、該当行に元記事リンクを付けて `候補` に進める。4本が全部そろうのを待たず、記事ごとに進めてよい。
3. **おふとんの暖かさ**は[元記事がある](https://github.com/nozomitaguchi/everyday-trivia/blob/main/trivia/futon-warmth.md)ので、動画に進める題材として扱う。見送りにした「干したふとんのにおい」と混ざらないよう、暖かさの回は別の動画IDで登録する。
4. 制作順は、既に優先指定された「かぜの熱」「つめと髪」を先にして、追加分は **おふとん → 鍵 → 冬の木 → 雨と雪 → トイレ**を目安にする。「雨と雪」の公開順は制作中の「白い雲と雨雲」のあとを目安にする。

作業報告には、元記事の公開URL、検証した出典、動画にするときの見せ場、変えた制作ステータスをテーマごとに書いてください。
