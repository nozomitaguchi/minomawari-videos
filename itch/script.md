## 1. つかみ（蚊にさされたうで。かくと すっ → 少したつと もっとかゆい）
- N: 蚊にさされたところが、むずむず、かゆい。
- N: かくと、すっとして、気持ちがいいですね。
- N: ところが、少したつと、前よりもっと、かゆくなっていることがあります。
- S（吹き出し）: かいたら もっと かゆい！
- N: かゆいところをかくと、どうして、もっとかゆくなるんでしょう。

## 2. 予想（正解は3番）
- N: どうしてだと思う？ 予想してみよう。
- N: 1番。つめに、ばいきんがいるから。
- N: 2番。かくと、皮ふが熱くなるから。
- N: 3番。脳の痛みどめが、かゆみも強くするから。
- N: まずは、かゆみがどこから来るのか、見てみましょう。

## 3. かゆみは「ひっかきたくなる」いやな感じ（虫などを はらいのけて 体を守るため、と考えられている）
- N: かゆみは、「ひっかきたくなる」、いやな感じのことです。
- N: 体についた虫などを、はらいのけて、体を守るためだと考えられています。

## 4. 皮ふの中：見張り役の細胞が「かゆみのもと」を出し、浅いところまでのびた細い神経が受け取る
- N: 皮ふの中には、見張り役の細胞がいます。
- N: 蚊のだ液などに気づくと、「かゆみのもと」のつぶを、パッと出します。
- N: 皮ふの浅いところまでのびた、細い神経が、それを受け取ります。

## 5. 合図は せきずいを通って脳へ。脳にとどいて はじめて「かゆい」
- N: 合図は、背骨の中の「せきずい」を通って、脳へ向かいます。
- N: 脳にとどいて、はじめて「かゆい」とわかるんです。

## 6. かくと ちょっぴり痛い → 痛みの合図が せきずいで かゆみの合図をしずめる → すっとする
- N: では、かくと、どうなるでしょう。
- N: かくと、皮ふが、ちょっぴり痛くなります。
- N: その痛みの合図が、せきずいで、かゆみの合図をしずめます。
- N: だから、かいた瞬間は、すっとするんです。
- B（吹き出し）: すっと した！

## 7. いちばんの見せ場：脳が痛みをおさえようとセロトニンを出す → かゆみの神経まで元気に → かゆみが強くなる（ネズミの研究）
- N: でも、脳は、痛みをおさえようとして、「セロトニン」というものを出します。
- N: セロトニンは、脳から、せきずいへ広がっていきます。
- N: そのとき、かゆみの神経まで、元気にしてしまうんです。
- N: それで、かゆみが、前より強くなります。
- N: これは、ネズミの研究でわかったことです。
- N: 人でも、同じことが起きていると考えられています。

## 8. かいた傷から また「かゆみのもと」→「かゆい・かく・もっとかゆい」の輪
- N: それだけではありません。かいて皮ふに傷ができると、そこからまた、「かゆみのもと」が出てきます。
- N: かゆい、かく、もっとかゆい。ぐるぐる回る、輪になってしまうんです。
- K（吹き出し）: ぐるぐる〜

## 9. 正解と、みてみよう（かく前に冷やしてみる。つめでかきむしらない・氷はタオルでまく・続くときはお医者さん）
- N: 正解は3番。脳の痛みどめが、かゆみまで強くしていたんだね。
- N: 今度かゆくなったら、かく前に、冷やしてみよう。
- N: 大人に、氷をタオルでまいてもらって、かゆいところに当てます。
- N: かいたときと、冷やしたときで、少したってからのかゆさを、くらべてみよう。
- N: つめで、かきむしらないでね。氷は、かならずタオルでまこう。
- N: かゆみが続くときや、赤くはれたときは、大人に言って、お医者さんにみてもらおう。

## 言いかたの注意（メモから）
- セロトニンの話はネズミの研究（ワシントン大学 2014年）。「人でも同じことが起きていると考えられている」まで。「人でわかった」とは言わない
- 蚊は入口（つかみ・見張り役が気づくもの）だけ。蚊の口やだ液のくわしい話は蚊の回（mosquito-bite）
- 冷やすとなぜやわらぐか、のしくみは言わない。「かく前に冷やしてみて、くらべる」まで
- 「かくのは ぜったい だめ」と叱る言い方にしない。「つめで かきむしらない」にとどめる
- アトピー性皮膚炎・サルの実験・見るだけでうつる話は、この動画では入れていない（長さのため）
- 色の約束：かゆみの合図＝オレンジの波線、痛みの合図＝赤の矢印、かゆみのもと＝黄色のつぶ、セロトニン（脳の痛みどめ）＝むらさきのつぶ、冷たい＝青
