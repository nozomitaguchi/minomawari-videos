## 2. 予想

## 3. 鼻の中の見張り役
- N: 鼻の中のかべには、見張り役の神経があります。
- N: ほこりや花粉、けむりのような細かいつぶが入ると、見張り役が気づきます。
- K（吹き出し）: みはりやく はっけん！
- N: 急に冷たい空気を吸ったときにも、くしゃみが出ることがあります。

## 4. 知らせは脳のおくの「延髄」へ（反射）
- N: 見張り役は、「じゃまものが来た！」と、脳に知らせます。
- N: 知らせがとどくのは、脳の下のほうにある「延髄」というところ。
- N: そこから、胸やおなか、のどの筋肉に、命令が出ます。
- N: 考える前に、体がかってに動く。これを「反射」といいます。

## 5. 吸う・ためる・ドカン
- N: 命令は、毎回、同じ順番で進みます。
- N: まず「吸う」。横隔膜などの筋肉がちぢんで、空気をたくさん吸いこみます。
- B（吹き出し）: はっ… はっ…
- N: つぎに「ためる」。のどちんこが下がって、鼻のおくへの通り道をふさぎます。
- N: さいごに「ドカン」。のどのすき間が開いて、空気が鼻から、いっきに出ていきます。

## 6. くしゃみの息の速さ、しぶき、そででおおう
- N: くしゃみの息は、いちばん速いときで、1秒に10メートルから30メートルに達することがあります。
- N: しぶきは、2メートルほど飛び、病気のもとが入っていることもあります。
- N: だから、手ではなく、そでの内がわやティッシュで、口と鼻をおおいます。

## 7. 鼻の中の「リセット」、まぶしい光

- N: くしゃみの押す力は、鼻水を送り出すはたらきの、スイッチを入れます。
- N: まるで、鼻の中の「リセット」ですね。
