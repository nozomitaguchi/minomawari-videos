# くも 台本

タイトル：白い雲と黒っぽい雨雲、何がちがうの？｜みのまわり図鑑 くも
出どころ：everyday-trivia `trivia/sky-cloud-white.md`・`trivia/sky-words.md`
正解：1番（cast.py）／吹き出し：S → B → S


## 1. つかみ（hook）
- N: 青い空に、ぷかぷかうかぶ雲。まっ白ですね。
- N: でも、雨がふりそうなときの雲は、灰色や、黒っぽく見えます。
- S（吹き出し）: おなじ くもなのに？
- N: どちらも同じ水のつぶの集まりなのに、どうして色がちがうんでしょう。

## 2. 予想（guess）
- N: 雨雲が黒っぽく見えるのは、どうしてだと思う？
- N: 1番。光が、下までぬけられないから。
- N: 2番。雲の中に、黒いすなが入っているから。
- N: 3番。雨の水が、黒い色をしているから。
- N: 答えをさがしに、まずは、雲が何でできているか見てみましょう。

## 3. 雲は水のつぶ（drop）
- N: 雲は、とても小さな水や氷のつぶが、たくさん集まったものです。
- N: つぶの大きさは、髪の毛の太さの、5分の1くらい。

## 4. 雲のでき方（form）
- N: 空気が上にのぼると、ふくらんで冷えます。
- N: すると、空気の中の見えない水が、ちりにくっついて、つぶになります。
- N: 下からの風に支えられて、空にうかんでいるんです。

## 5. 空気のつぶと雲のつぶ（compare）
- N: 空が青いのは、とても小さな空気のつぶが、青い光を多く散らすから。
- N: 雲のつぶは、空気のつぶより、ずっと大きいんです。
- N: 大きなつぶは、どの色の光も、ほとんど同じだけ散らします。

## 6. だから白い（white）
- N: 太陽の光は、もともと白。
- N: 色がかたよらないので、雲は、太陽の光の白のまま見えるんです。
- B（吹き出し）: まっしろ！
- N: このしくみは、1908年に、ドイツのミーさんが計算しました。

## 7. 底が灰色（bottom）
- N: では、灰色の雲は、どうしてでしょう。
- N: 雲のつぶに散らされた光は、上や横へ行くことが多いんです。
- N: だから、雲の上や横は明るく、底のほうは光が届きにくくて、灰色に見えます。

## 8. 雨雲（rain）
- N: 雨雲には、大きな水のつぶが、たくさんあります。
- N: 光は、つぶに何度もぶつかって、向きを変えます。
- N: まっすぐ下へぬけられないので、雨雲は光をさえぎって、黒っぽく見えるんです。
- S（吹き出し）: まっくら〜

## 9. おまけ sky（words）
- N: おまけ。英語で、空のことを「スカイ」といいますね。
- N: スカイは、もともと「雲」という意味のことばだったんです。

## 10. 正解とみてみよう（look）
- N: 正解は1番。光が、下までぬけられないからだったんだね。
- N: もくもくした雲を、1つ選んでみよう。
- N: 日が当たっている上や横と、底のほうの色を、くらべてね。
- N: うすい雲と、雨がふりそうな厚い雲の底も、くらべてみよう。
- N: 太陽は、ぜったいに直接見ないでね。

## 11. おわり（end）
- S（吹き出し）: またね！
- B（吹き出し）: またねー！
