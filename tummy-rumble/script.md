# おなかの音 台本

タイトル：おなかは、どうしてグーと鳴る？｜みのまわり図鑑 おなかの音
出どころ：everyday-trivia `trivia/tummy-rumble-basics.md`・`tummy-rumble.md`・`tummy-rumble-words.md`・`tummy-rumble-history.md`

## 1. つかみ（hook）
- N: しずかなときに、「グー」。
- N: おなかが、大きな音で鳴ることがあります。
- S（吹き出し）: いまの なんの おと？
- N: いったい、何が鳴っているんでしょう。

## 2. 予想（guess）
- N: おなかのグーは、何の音だと思う？
- N: 1番。おなかの皮が、ふるえている音。
- N: 2番。胃や腸が、ガスと液体を押し流す音。
- N: 3番。おなかの中の虫が、鳴いている音。
- N: 答えをさがしに、おなかの中を、のぞいてみましょう。

## 3. 胃と腸（tube）
- N: おなかの中には、胃と、長い腸があります。
- N: 胃や腸のかべは、筋肉でできています。
- N: 根元から順に、しぼるように縮んで、中身を先へ送ります。
- N: 歯みがき粉のチューブを、しぼり出すような動きです。

## 4. 音が出る（sound）
- N: 中には、液体と、ガスがまざっています。
- N: 縮む波が、ガスと液体を押し流すとき、ゴロゴロと音が出るんです。
- B（吹き出し）: ゴロゴロ！
- N: 昔の人は、おなかの中の虫が鳴くと考えて、「腹の虫が鳴く」といいました。

## 5. からっぽだと大きい（empty）
- N: からっぽのときは、音をやわらげる食べものがないので、ひびいて大きく聞こえます。
- N: 食べたあとも鳴っていますが、食べものが音をくぐもらせるので、気づきにくいんです。

## 6. 空腹のときの動き（cycle）
- N: では、おなかがすくと、どうして大きなグーが鳴るのかな。
- N: 胃と腸がからっぽになると、特別な動きが始まります。
- N: しずかな時間、ときどき動く時間、そして、強くしぼる時間。
- N: これを、1時間半から2時間ごとに、くりかえします。
- N: 強くしぼる波が、ガスと液体を一気に押し流すとき、グーと大きく鳴るんです。

## 7. おそうじ係（clean）
- N: この強い波は、消化しきれなかったかすを、先へ押し流します。
- N: 研究者は、これを「そうじ係」のはたらきと、よんでいます。
- K（吹き出し）: おそうじ！

## 8. 合図のホルモン（hormone）
- N: 動きの合図を出すのは、血にのって運ばれる「ホルモン」です。
- N: 1977年、群馬大学の伊藤漸さんたちが、犬で、このしくみを確かめました。
- N: 食べると合図が下がって、この動きは止まります。

## 9. 正解とみてみよう（look）
- N: 正解は2番。胃や腸が、ガスと液体を押し流す音だったんだね。
- N: 大きなグーが鳴ったら、時計を見ておこう。
- N: 次の大きなグーまで、1時間半から2時間くらいか、たしかめてみよう。
- N: ごはんをぬいて、ためさなくていいからね。

## 10. おわり（end）
- S: またね！ / B: またねー！
