# セミ 台本

タイトル：セミは、どうして夏になくの？｜みのまわり図鑑 セミ

もとの記事：everyday-trivia `trivia/cicada-summer-song.md`（メモ：`ideas/notes/cicada.md`）

cast.py：正解は3番／吹き出しは S → K → B（おわりは S・B）

## 1. つかみ（夏の公園のセミの声 → 冬は聞こえない）
- N: 夏になると、木の上から、セミの大きな声が聞こえてきます。
- N: でも、冬の公園では、セミの声は聞こえません。
- S（吹き出し）: ふゆは どこに いるの？
- N: セミは、どうして夏になると鳴くんでしょう。

## 2. 予想（正解は3番）
- N: 予想してみよう。夏に鳴いているセミは、夏になる前、どこにいたのかな？
- N: 1番。あたたかい南の国へ、飛んでいっていた。
- N: 2番。木のあなの中で、ねむっていた。
- N: 3番。土の中で、くらしていた。
- N: まずは、セミの声のひみつから見てみましょう。

## 3. 鳴くのはオスだけ
- N: 鳴いているのは、じつは、オスのセミだけです。
- N: オスは、メスに向かって、「ここにいるよ」とアピールしているんです。
- N: メスは鳴きません。音を出すしくみが、オスにしかないからです。

## 4. 音はおなかの太鼓
- N: セミは、のどで鳴いているのではありません。
- N: 音を出すのは、おなかです。
- N: おなかの中の筋肉が、音の出るまくを引っぱると、カチッと鳴ります。
- N: オスのおなかは、中が空っぽ。
- N: たいこの胴のように音がひびいて、大きな声になるんです。
- K（吹き出し）: おなかが たいこ！

## 5. メスはおなかの耳で聞く
- N: メスは鳴かないけれど、ちゃんと聞いています。
- N: 耳は、おなかの下がわにあって、オスにもメスにもあるんですよ。

## 6. 土の中で何年も
- N: では、どうして夏なんでしょう。
- N: ひみつは、土の中にあります。
- N: セミは、幼虫のあいだ、土の中でくらします。
- N: はりのような口を木の根にさして、根がすった水をすっているんです。
- N: 土の中にいる長さは、種類や場所によって、2年から十数年。
- N: よく「7年」と言われますが、決まっているわけではありません。

## 7. 夏の夜に出てきて、おとなは1か月ほど
- N: 夏の夕方から夜、幼虫は土から出てきて、木にのぼります。
- N: そして、からをぬいで、おとなのセミになります。
- N: おとなのセミが生きるのは、数週間から1か月ほど。
- B（吹き出し）: つちの なかが ながい！
- N: だから、セミの声が聞こえるのは、地上にいる短いあいだだけなんです。

## 8. 種類で鳴く季節がちがう
- N: 鳴きはじめる時期は、セミの種類によってちがいます。
- N: 東京の記録では、7月のはじめにニイニイゼミ、おわりごろにツクツクボウシが鳴きはじめました。
- N: 春の4月から6月に、松林で鳴く、ハルゼミというセミもいます。

## 9. 正解 と みてみよう
- N: 正解は3番。夏に鳴いているセミは、それまで、土の中でくらしていたんだね。
- N: 夏になったら、同じ公園で、朝と夕方にセミの声を聞きくらべてみよう。
- N: 木のみきや枝のぬけがらや、根もとの土にある、出てきたあなも、さがしてみてね。
- N: 暑い日は大人といっしょに、ぼうしをかぶって、水を持って出かけよう。
- N: 木にはのぼらないで、見える高さだけさがしてね。

## 10. おわり
- S（吹き出し）: またね！
- B（吹き出し）: またねー！

## 絵のメモ
- 膜がへこんで「カチッ」と鳴るくわしい動きは、オーストラリアのセミの研究（Young & Bennet-Clark 1995）。概要欄に注を入れる。
- 絵の「ミーン ミン」は雰囲気の文字（ナレーションでは言わない）。
- 7月の鳴きはじめは自然教育園（東京都港区）の2000年代の平均：ニイニイゼミ7/3、ヒグラシ7/11、ミンミンゼミ7/16、アブラゼミ7/19、ツクツクボウシ7/28。
- なぜ夏に出てくるのか（合図）は元記事にないので言わない。
- 土の中と地上の長さをくらべる帯は、見やすい長さ（実際の比ではない）。
