# しんぞう 台本

タイトル：走ると、どうして心臓がドキドキするの？｜みのまわり図鑑 しんぞう

もとの記事：everyday-trivia `trivia/heartbeat-running.md`（メモ：`ideas/notes/heartbeat-running.md`）

cast.py：正解は3番／吹き出しは B → S → B（おわりは S・B）

## 1. つかみ（公園でかけっこ。走ったあと、むねに手を当てると）
- N: 公園でかけっこ。走ったあと、むねに手を当ててみると。
- B（吹き出し）: ドキドキ してる！
- N: 心臓が、速く、強く打っています。
- N: 走ると、どうして心臓がドキドキするんでしょう。

## 2. 予想（正解は3番）
- N: 予想してみよう。走っているとき、心臓は、何をふやしているのかな？
- N: 1番。打つ回数だけ。
- N: 2番。1回に送り出す、血の量だけ。
- N: 3番。回数も量も、両方。
- N: まずは、心臓のはたらきを見てみましょう。

## 3. 心臓は、血を送り出すポンプ
- N: 心臓は、血を送り出すポンプです。
- N: 体からもどった血を肺へ送り、肺で酸素をもらった血を、体じゅうへ送り出します。
- N: 「ドックン」という音は、心臓の中のとびらが、パタンとしまる音です。

## 4. 走る筋肉は、酸素を使って力を出す
- N: 走っている足の筋肉は、酸素を使って、力を出しています。
- N: その酸素を運んでくるのは、血です。
- N: だから走ると、筋肉は、酸素をもっとほしがります。

## 5. 心臓は「回数」と「1回の量」を両方ふやす
- N: そこで心臓は、打つ回数をふやします。
- N: そのうえ、強くちぢんで、1回に送り出す血の量もふやします。
- N: 両方をふやすので、送り出す血は、休んでいるときの4倍から5倍にもなります。
- S（吹き出し）: りょうほう なんだ！

## 6. ふえた血は、走っている筋肉へ
- N: ふえた血のほとんどは、走っている筋肉へ向かいます。
- N: 筋肉の血管は広がり、胃や腸など、走るのに使わないところの血管は、せまくなります。
- N: 筋肉は、とどいた血から、酸素をいつもよりたくさん受け取ります。

## 7. 心臓のアクセルとブレーキ
- N: 心臓は、「速くなれ」と思って、速くしているのではありません。
- N: 心臓には、速くする神経と、おそくする神経がつながっています。
- N: 車の、アクセルとブレーキのようです。
- N: 走ると、ブレーキがゆるんで、アクセルがふまれます。
- N: 脳は、走り出す前から、もう準備を始めています。

## 8. 止まると、最初の1分ほどで ぐっとゆっくりに
- N: 走るのをやめると、心臓は、最初の1分ほどで、ぐっとゆっくりになります。
- N: そのあとは、少しずつ、もとにもどっていきます。
- B（吹き出し）: ゆっくりに なった！
- N: 子どもの心臓は、大人よりも速く打っています。

## 9. 正解 と みてみよう
- N: 正解は3番。心臓は、打つ回数も、1回の量も、両方ふやしていたんだね。
- N: 走る前に、むねに手を当てて、大人に10秒はかってもらい、「ドックン」の数を数えよう。
- N: 少し走ったあとに、もう一度数えて、くらべてみてね。
- N: 走るのは、広くて、車の来ない場所で。むりに速く、長く走らないでね。
- N: 苦しいときや、むねがいたいときは、すぐに止まって、大人に言おう。

## 10. おわり
- S（吹き出し）: またね！
- B（吹き出し）: またねー！

## 絵のメモ
- 色の約束（サイトの図と同じ）：酸素の多い血＝あか、酸素の減った血＝むらさき、酸素＝きいろのつぶ、アクセル（速くする神経＝交感神経）＝オレンジ、ブレーキ（おそくする神経＝副交感神経）＝あお。
- 「4〜5倍」は、OpenStax の「体重70kgの人・健康な若い人」の例（1分に約5.25L → 約19.5L）。子どもの数字ではないので、75回・150回・70mL・130mL は、ナレーションでも絵でも出さない。打つ回数のしるしと、コップの量は「ふえる」ことだけを見せる（数は合わせていない）。
- 心臓の絵は、むかって左（心臓の右側）が体からもどった血、むかって右（心臓の左側）が肺からもどった血。血のめぐる道・心臓・とびら（弁）は、かんたんに描く。
- 「ドックン」：「ドッ」は入口の弁、「クン」は出口の弁がしまる音（MSDマニュアル家庭版）。ナレーションでは「心臓の中のとびら」と言い、絵に「とびら（べん）」と入れる。
- ふえた血の行き先は「ほとんどが走っている筋肉へ」。割合（％）は言わない。
- 筋肉が受け取る酸素：休んでいるときは届いた酸素の20〜40％、激しい運動では約70〜80％（Korthuis 2011）。絵は10このうち3こ／7〜8こ。数字は言わない。
- 「走る前からドキドキする」とは言わない。「脳は、走り出す前から、もう準備を始めています」まで。
- 休みにもどるまで何分、とは言わない（「最初の1分ほどで速く、そのあとゆっくり」まで）。グラフは形だけで、めもりは入れない。
- 子どもの心臓が速い理由は言わない（資料にない）。
- みてみようの注意：広くて車の来ない場所で・むりに速く長く走らない・苦しい／むねがいたいときはすぐ止まって大人に言う。
