# そらの色 台本（案）

タイトル：昼は青いのに、どうして夕やけは赤い？｜みのまわり図鑑 そら

## 1. つかみ（昼→夕方に空が変わる）
- N: おひるの空は、きれいな青。
- N: でも夕方になると、赤やオレンジに変わります。
- S（吹き出し）: おなじ そらなのに？
- N: 同じ空なのに、どうして色が変わるんでしょう。

## 2. 予想
- N: どうしてだと思う？ 予想してみよう。
- N: 1番。海の青が、空にうつっている。
- N: 2番。空気が、光を飛びちらせている。
- N: 3番。空の上に、青いまくがある。
- N: 答えをさがしに、まずは身近な空気から見てみましょう。

## 3. 空気は透明、でも厚い
- N: コップの中の空気には、色がありません。
- N: でも空気は、地面から空の上まで、とても厚く重なっています。
- N: その中を、太陽の光が通ってきます。

## 4. 太陽の光は色のまぜもの
- N: 太陽の光は白っぽく見えますが、じつは、いろんな色がまざっています。
- N: 三角のガラス、プリズムに通すと、虹のように色が分かれます。
- N: 1666年に、イギリスのニュートンが確かめました。

## 5. 散乱
- N: 光が、空気のとても小さなつぶにぶつかると、向きを変えて、あちこちへ飛びちります。
- N: これを「散乱」といいます。
- N: 波の短い青い光は、赤い光の何倍も、飛びちりやすいんです。
- B（吹き出し）: あおが ぴょんぴょん！

## 6. どこからでも青
- N: 飛びちった青い光は、空のあらゆる方向から、目に届きます。
- N: だから、太陽のない方を見上げても、空は明るく青いんです。
- N: 海の色がうつっているわけでは、ありません。

## 7. むらさきじゃないわけ
- N: でも、むらさきの光は、青よりもっと飛びちりやすいはず。
- N: 太陽の光にはむらさきが少なく、人の目もむらさきを感じにくいので、空は水色に見えます。

## 8. 夕やけ
- N: では、夕方はどうでしょう。
- N: 太陽が低くなると、光は空気の中を、ななめに長い道のりで通ってきます。
- N: そのあいだに、青い光は途中で飛びちりきってしまいます。
- N: 最後まで残るのは、飛びちりにくい、赤やオレンジの光。
- N: だから夕やけは、赤く見えるんです。

## 9. おまけ：火星
- N: ちなみに火星では、反対のことが起きます。
- N: 昼の空は黄色っぽい茶色で、夕日のまわりが、青くなるんです。
- K（吹き出し）: はんたいだ〜

## 10. 正解とみてみよう
- N: 正解は2番。空気が光を飛びちらせて、空の色ができていたんだね。
- N: 晴れた日は、太陽に背中を向けて、空を見上げてみよう。
- N: 夕方は、空の下のほうの色がどう変わるか、くらべてみよう。
- N: 太陽は、ぜったいに直接見ないでね。

## 11. おわり
- S: またね！ / B: またねー！
