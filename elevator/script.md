# エレベーター 台本

タイトル：エレベーターは、どうやって上がる？｜みのまわり図鑑 エレベーター
出どころ：everyday-trivia `trivia/elevator-basics.md`・`elevator-history.md`・`elevator-door-safety.md`

## 1. つかみ（hook）
- N: ボタンをおすと、エレベーターのへやは、すーっと上がっていきます。
- S（吹き出し）: だれが もちあげてるの？
- N: 人がたくさん乗った、重いへや。
- N: いったい、どうやって上げているんでしょう。

## 2. 予想（guess）
- N: へやをつっているロープの反対がわには、何がついていると思う？
- N: 1番。大きなばね。
- N: 2番。へやと同じくらい重い、おもり。
- N: 3番。何もついていない。
- N: 答えをさがしに、エレベーターの通り道を、のぞいてみましょう。

## 3. かごとロープ（cage）
- N: 人が乗るへやは「かご」といいます。
- N: かごは、じょうぶなロープで、つり下げられています。
- N: 建物の上には、かごを動かすモーターがあります。

## 4. 車とロープ（sheave）
- N: モーターは、滑車という車をまわします。
- N: ロープは、車に巻きとるのではなく、かけてあるだけ。
- N: 車とロープがこすれる力で、ロープが送られて、かごが動くんです。

## 5. おもり（weight）
- N: ロープの反対がわには、かごとつり合う、重い「おもり」がついています。
- N: かごが上がると、おもりは下がります。
- N: シーソーと同じで、モーターは、少しの力で動かせるんです。
- B（吹き出し）: シーソーだ！

## 6. 落ちないの？（ropes）
- N: でも、ロープが切れたら、落ちちゃわないかな。
- N: ロープはふつう3本以上あって、1本切れても、落ちないようになっています。
- N: もしものときに、かごを止める「非常止め」という装置もあります。

## 7. オーチスのしかけ（otis）
- N: ロープが切れても落ちないしかけを作ったのは、アメリカのエリシャ・オーチスです。
- N: ロープが切れると、ばねがパッと開いて、両がわのぎざぎざの棒にかみこみ、台が止まります。
- N: 1854年、オーチスは、みんなの前で台に乗って高く上がり、ロープを切らせました。
- N: 台はその場で止まり、見ていた人たちは大よろこび。
- K（吹き出し）: ぴたっ！
- N: これで、エレベーターは、安心して乗れるものになりました。

## 8. ドア（door）
- N: ドアにも、ひみつがあります。
- N: ドアは、かごのドアと、乗り場のドアの2まいが、いっしょに動きます。
- N: ドアが閉まっていないと、エレベーターは動きません。
- N: かごがその階に止まったときだけ、ドアが開くんです。

## 9. 何人乗り（capacity）
- N: かごの中には、「何人乗り」と「何キロ」が書いてあります。
- N: 乗れる人数は、ひとり65キロとして、決められているんです。

## 10. 正解とみてみよう（look）
- N: 正解は2番。ロープの反対がわには、かごとつり合う、おもりがついていたんだね。
- N: 次に乗ったら、「何人乗り何キロ」の表示をさがして、キロを人数でわってみよう。
- N: 65に、近くなるかな。
- N: ドアが動いているときは近づかないで、足もとのすき間は、見るだけにしてね。

## 11. おわり（end）
- S: またね！ / B: またねー！
