# ダンゴムシ 台本

タイトル：ダンゴムシは、どうして丸くなる？｜みのまわり図鑑 ダンゴムシ
出どころ：everyday-trivia `trivia/pill-bug-rolls-up.md`・`pill-bug-basics.md`・`pill-bug-land-life.md`

## 1. つかみ（hook）
- N: 石の下や、落ち葉の下にいる、ダンゴムシ。
- N: さわると、くるんと、ボールのように丸くなります。
- S（吹き出し）: まんまるだ！
- N: どうして、丸くなるんでしょう。

## 2. 予想（guess）
- N: ダンゴムシが丸くなるのは、何のためだと思う？
- N: 1番。ころがって、速くにげるため。
- N: 2番。やわらかいおなかをかくして、体を守るため。
- N: 3番。ねむるため。
- N: 答えをさがしに、まずはダンゴムシの体を、よく見てみましょう。

## 3. 虫じゃない（body）
- N: ダンゴムシは、名前に「ムシ」とつくけれど、昆虫ではありません。
- N: じつは、エビやカニの仲間です。
- N: 脚は14本。昆虫の6本より、ずっと多いんです。

## 4. かたい背中、やわらかいおなか（shell）
- N: 背中は、かたい殻でおおわれています。
- N: 背中には、弓のように曲がった板が、ならんでいます。
- N: でも、おなかの側は、やわらかいんです。

## 5. 敵（enemy）
- N: ダンゴムシを食べる敵には、カエルやカマキリ、クモやアリがいます。
- N: 敵が近づくと、丸くなって、やわらかいおなかをかくし、かたい殻で体を守るんです。
- B（吹き出し）: かくれた！

## 6. きっかけ（trigger）
- N: さわられたときや、ゆれを感じたときに、丸くなることが多いんです。
- N: 頭の触角では、ものの形や、においなどを感じているといわれています。
- N: 東京の子どもたちの研究では、電子ホイッスルの音を聞かせると、5ひきとも、動きを止めました。

## 7. すき間なく丸まる（ball）
- N: 丸くなるときは、背中の板と、おなかの筋肉で、体をぎゅっと曲げます。
- N: 触角は、頭のくぼみに、ぴったりたたみます。
- N: 脚は、おなかの溝にしまいます。
- N: だから、すき間のない、まんまるの球になるんです。
- K（吹き出し）: すきま なし！

## 8. 本当に守れる？（protect）
- N: 本当に、守れるのかな。
- N: アメリカの研究で、ダンゴムシと、丸くなれない仲間を、アリといっしょにしてみました。
- N: すると、丸くなれない方が、たくさんおそわれました。
- N: 丸い体はつるつるで、敵がかみつくところを、見つけにくいんです。

## 9. 水も守る（water）
- N: それに、かわいた空気の中では、丸くなると、体から逃げる水が、3分の1ほどへります。
- N: ダンゴムシは、かわくと息ができなくなるので、これも大事なんです。

## 10. 正解とみてみよう（look）
- N: 正解は2番。やわらかいおなかをかくして、体を守っていたんだね。
- N: 丸まったダンゴムシを見つけたら、触角や脚が見えているか、すき間があるか、見てみよう。
- N: しばらく待つと、のびて、また歩き出すよ。
- N: さわったり、ゆらしたりしないで、見るだけにしてね。

## 11. おわり（end）
- S: またね！ / B: またねー！
