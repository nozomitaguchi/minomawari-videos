# かぜ 台本（案）

タイトル：風は、どうして ふくの？｜みのまわり図鑑 かぜ

出どころ：everyday-trivia `trivia/wind-blow.md`（メモ：`ideas/notes/wind.md`）
cast.py：正解は3番、吹き出しは B → S → B


## 1. つかみ（公園の旗がパタパタ。でも風は見えない）
- N: 公園の旗が、パタパタとゆれています。
- N: 風がふいているんですね。でも、風は目に見えません。
- B（吹き出し）: だれが おしてるの？
- N: 風は、どうしてふくんでしょう。

## 2. 予想（晴れた日のお昼、海辺の旗はどっちになびく？）
- N: 予想してみよう。晴れておだやかな日のお昼、海辺に旗が立っています。
- N: 旗は、どっちになびくかな？
- N: 1番。海のほうへ、なびく。
- N: 2番。風がなくて、たれさがる。
- N: 3番。陸のほうへ、なびく。
- N: 答えをさがしに、まずは風の正体から見てみましょう。

## 3. 風の正体は、動いている空気（空気には重さがある）
- N: 風の正体は、動いている空気です。
- N: 空気は目に見えませんが、重さがあります。
- N: 上にある空気の重さが、下の空気や地面を、ぎゅっと押しているんです。

## 4. 空気の「おしくらまんじゅう」（強いほうから弱いほうへ）
- N: 空気は、となりどうしで、いつも押し合っています。まるで、おしくらまんじゅう。
- N: ふくらんだ風船を押すと、中の空気が押し返してくるのと同じです。
- N: 押す力の強いほうから、弱いほうへ、空気は押し出されます。
- N: これが、風です。
- S（吹き出し）: おされて ビューッ！

## 5. あたたまった空気はのぼる → まわりから流れこむ
- N: では、押す力のちがいは、どうしてできるんでしょう。
- N: おもなわけは、場所による、あたたかさのちがいです。
- N: お日さまであたたまった空気は、軽くなって、上へのぼります。
- N: すると、下の押す力が弱くなって、まわりから空気が流れこむんです。

## 6. 海辺のお昼：うみかぜ（上では反対向き、ぐるりと回る）
- N: 海辺で見てみましょう。陸は海より、あたたまりやすくて、冷えやすいんです。
- N: 晴れた日のお昼は、陸の上の空気のほうが、あたたかくなります。
- N: 陸で空気がのぼって、そこへ海から空気が流れこみます。
- N: 海から陸へふく、この風を「うみかぜ」といいます。
- B（吹き出し）: うみから きた！
- N: 空の上では反対向きに流れて、ぐるりと回っています。

## 7. 夜：りくかぜ
- N: 夜になると、こんどは陸のほうが冷えます。
- N: 風は反対に、陸から海へふきます。これが「りくかぜ」です。

## 8. 入れかわる朝と夕方は「なぎ」
- N: うみかぜと、りくかぜが入れかわる朝と夕方には、風が弱くなります。
- N: これを「なぎ」といいます。
- N: 朝のなぎは「あさなぎ」、夕方のなぎは「ゆうなぎ」ともいいます。

## 9. 正解と みてみよう
- N: 正解は3番。お昼は海から風がふくので、旗は陸のほうへなびくんだね。
- N: 晴れておだやかな日に海の近くへ行ったら、お昼と夕方で、旗の向きをくらべてみよう。
- N: 「お昼は海からふいてくるはず」と、予想してから見てみてね。
- N: 海辺は大人といっしょに歩いて、風の強い日は近づかないでね。

## 10. おわり
- S（吹き出し）: またね！
- B（吹き出し）: またねー！
