# シャボン玉 台本

タイトル：シャボン玉は、どうして丸くなるの？｜みのまわり図鑑 シャボンだま

もとの記事：everyday-trivia `trivia/soap-bubble-round.md`（メモ：`ideas/notes/soap-bubble.md`）

## 1. つかみ（ふくと ぐにゃっと のびる。はなれると まんまる）
- N: シャボン玉をふくと、まくは、ぐにゃっと長くのびます。
- N: でも、輪からはなれたとたん、まんまるになって飛んでいきます。
- B（吹き出し）: まんまるだ！
- N: シャボン玉は、どうして丸くなるんでしょう。

## 2. 予想（正解は1番）
- N: 予想してみよう。星の形の輪でふくと、どんな形のシャボン玉が出るかな？
- N: 1番。まるい玉。
- N: 2番。星の形の玉。
- N: 3番。星と丸がまざった、でこぼこの玉。
- N: まずは、シャボン玉のまくを見てみましょう。

## 3. まくのつくり（うすい石けん水のまく。ちぢもうとする）
- N: シャボン玉は、空気をつつんだ、とてもうすい石けん水のまくです。
- N: まくの外がわと内がわには、石けんのつぶが、ずらりとならんでいます。
- N: このまくは、のびたゴムのように、いつもちぢもうとしています。

## 4. 糸の実験（まくが引っぱっている）
- N: 丸い輪に糸をゆるくわたして、石けん水のまくをはります。
- N: 糸のかたがわのまくを、わってみると…
- N: 糸は、のこったまくに引っぱられて、ぴんとはります。
- S（吹き出し）: ひっぱられた！
- N: まくが、ちぢもうとして引っぱっているんです。

## 5. 輪からはなれると、ちぢんで まるい玉に
- N: まくは、いつも、いちばん小さくなろうとします。
- N: 輪からはなれて口がとじると、中の空気の量は、もう変わりません。
- N: まくは、その空気をつつんだまま、ちぢんでいきます。
- N: まくがちぢもうとすると、中の空気がおし返します。
- N: こうして、いちばん小さくなった形が、まるい玉なんです。

## 6. 同じ空気をつつむなら、まるい玉がいちばん小さい
- N: 同じ量の空気を、いろいろな形でつつんでみましょう。
- N: とんがりぼうしの形、さいころの形、そして、まるい玉。
- N: つつむまくがいちばん少なくてすむのは、まるい玉です。

## 7. だから、星の輪でも まるい玉
- N: だから、星の輪でふいても、出てくるのは、まるい玉。
- N: 四角や三角、三日月の輪でためしても、まるい玉しかできませんでした。
- N: 輪の形になるのは、まくが輪にくっついているあいだだけなんです。
- B（吹き出し）: ほしでも まる！

## 8. 2つくっつくと、かべができる
- N: では、シャボン玉が2つくっつくと、どうなるでしょう。
- N: あいだに、1まいのかべができます。同じ大きさなら、かべはまっ平ら。
- N: 大きさがちがうと、小さいほうが、大きいほうへふくらみます。
- N: 大きさのそろったあわがたくさんならぶと、ハチの巣のような六角形に見えます。

## 9. 正解 と みてみよう
- N: 正解は1番。星の輪でふいても、まくがちぢんで、まるい玉になるんだね。
- N: モールで、丸や四角、星の輪を作って、ためしてみよう。
- N: 石けん水は、口に入れないでね。ストローは、すわずにふこう。
- N: 人の顔に向けてふかないで。目に入ったら、こすらずに、水道の水でよくあらおう。
- N: 遊ぶときは、庭など、外でね。

## 10. おわり
- S（吹き出し）: またね！
- B（吹き出し）: またねー！

## 絵のメモ
- 色の約束（図鑑の絵とそろえる）：まく＝青みの線、石けんのつぶ＝青いあたま＋オレンジのしっぽ、ちぢむ力＝赤い矢印、空気がおし返す力＝緑の矢印、輪（モール）＝オレンジ。
- 「とんがりぼうし・さいころ・まるい玉」の棒の長さは、同じ体積（4.18…）をつつむ表面積 16.09…・15.59…・12.56…（北海道大学 数学博物館）の比。ナレーションでは数字を言わず、概要欄に入れる。
- 「四角・三角・三日月・星の輪でも丸い玉しかできなかった」は大阪市立科学館のサイエンスショーの実験。糸の実験も同じ資料。
- 「まるは、つつむまくがいちばん少なくてすむ形」と言う。「いちばんじょうぶ」「空気がおすから丸い」とは言わない。
- 「石けんが引っぱる力を強くする」とは言わない（石けんは弱める）。この動画では水だけの泡・われるしくみには入らない。
- 120度は絵にも入れない（子どもには角度がむずかしいため）。ハチの巣のような六角形は「大きさのそろったあわがたくさんならぶと」。
- はなれた直後にぷるぷるゆれるのは絵の動きだけ（ナレーションでは言わない）。まくの厚さ・つぶの大きさ・空気のつぶは、見やすいように描く。
