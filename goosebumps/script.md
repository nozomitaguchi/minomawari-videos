# とりはだ 台本（案）

タイトル：寒いと、どうして鳥肌が立つの？｜みのまわり図鑑 とりはだ

出どころ：everyday-trivia `trivia/goosebumps-cold.md`（メモ：`ideas/notes/goosebumps.md`）
cast.py：正解は3番、吹き出しは S → K → B

色の約束：毛の根もとの筋肉（立毛筋）＝赤、神経の合図＝黄色、毛＝こげ茶、空気＝水色のつぶ、熱＝オレンジの矢印

## 1. つかみ（冬の朝、パジャマをぬぐと、ぶるっ）
- N: 冬の朝、パジャマをぬぐと、ぶるっ。
- N: 腕や太ももが、ぶつぶつになります。
- S（吹き出し）: うで、ぶつぶつ！
- N: これが「鳥肌」。羽をとった鳥の肌に、にているので、こうよびます。
- N: 寒いと、どうして鳥肌が立つんでしょう。

## 2. 予想
- N: どうしてだと思う？ 予想してみよう。
- N: 1番。寒さで、皮ふがちぢんで、しわになるから。
- N: 2番。皮ふの下に、あせのつぶがたまるから。
- N: 3番。毛の根もとで、小さな筋肉がちぢむから。
- N: まずは、ぶつぶつを近くで見てみましょう。

## 3. ぶつぶつの正体（ルーペ → 皮ふを横から切った絵）
- N: ルーペで大きくすると、ぶつぶつの真ん中から、細い毛が出ています。
- K（吹き出し）: まんなかに け！
- N: これは、皮ふを横から切って、中を見た絵です。
- N: 毛は、皮ふにななめに生えていて、根もとに小さな筋肉がついています。
- N: 名前は「立毛筋」。
- N: この筋肉がちぢむと、ねていた毛が引っぱられて、起き上がります。
- N: すると、毛のまわりの皮ふがもり上がります。これが、ぶつぶつの正体です。

## 4. 自分では動かせない（神経の合図で、勝手にちぢむ）
- N: この筋肉は、手や足の筋肉とちがって、自分では動かせません。
- N: 寒さを感じると、神経が合図を送って、筋肉が勝手にちぢむんです。
- N: だから鳥肌は、自分で立てることも、止めることもできません。

## 5. 毛を立てると、どんないいこと？（毛皮の動物・鳥）
- N: では、毛を立てると、どんないいことがあるんでしょう。
- N: 毛皮のある動物では、毛が立つと、毛と毛の間の空気の層が、厚くなります。
- N: 空気は熱を伝えにくいので、体の熱が、外へにげにくくなるんです。
- B（吹き出し）: くうきの もうふ！
- N: 鳥も、寒いと羽をふくらませて、羽の中に空気をためます。
- N: 毛を立てるのには、体を大きく見せて、敵をおどろかせる意味もあるのかもしれません。

## 6. 人は毛が少ない（それでも鳥肌は立つ）
- N: でも、人は体の毛が少ないので、毛を立てても、空気の層はほとんどできません。
- N: だから、あまりあたたかくはなりません。それでも、寒いと鳥肌は立つんです。
- N: 寒いとき、人の体は、筋肉をふるわせて熱を作ったりもしています。

## 7. こわいとき・音楽でも
- N: 鳥肌は、こわいときや、すてきな音楽に心を動かされたときにも、立つことがあります。

## 8. 正解とみてみよう
- N: 正解は3番。毛の根もとで、小さな筋肉がちぢんで、毛を立てていたんだね。
- N: 寒い日に着がえるとき、腕のぶつぶつを、近くでよく見てみよう。
- N: 真ん中に、細い毛が立っているかな。
- N: 腕と太もも、どちらに出やすいかも、くらべてみよう。
- N: わざと冷たい水をかけたり、寒い所に長くいたりするのは、やめようね。
- N: 冬の朝は、スズメがまるくふくらんでいるか、さがしてみよう。
- N: 鳥には近づかないで、遠くから見るだけにしようね。

## 9. おわり
- S: またね！ / B: またねー！

## 言い方のメモ（元記事とメモから）
- 「人の鳥肌は役に立たない（なごり）」と言いきらない。「人は毛が少ないので、あまりあたたかくならない」まで。
- 「体を大きく見せて敵をおどろかせる」は推測なので「〜のかもしれません」。
- 「交感神経」は画面のラベル（こうかんしんけい）だけ。ナレーションは「神経が合図を送って」。
- マウスの研究（寒さが長くつづくと新しい毛）は、4分におさめるために入れていない（概要欄にも書かない）。
- 「手のひらには鳥肌が立たない」は確かめられていないので言わない。
- みてみよう：わざと体を冷やさない／鳥には近づかず遠くから見るだけ、を必ず言う。
